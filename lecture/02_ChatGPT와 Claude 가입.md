# 모듈 2. ChatGPT와 Claude 가입하기

← [[01_구글 계정 3개 만들기]] | 다음 → [[03_프롬프트·파일·폴더 활용]]

📌 **사전 과제 모듈입니다.** 수업 시간에는 다루지 않으니 수업 전에 이 페이지를 보며 혼자 따라 해 주세요. 막히면 첫날 수업 시작 전에 물어보세요.

> 모든 가입은 **"업무" Chrome 프로필 창**에서 진행합니다.
> 두 서비스 모두 **"Google로 계속하기"** 를 쓰면 비밀번호를 새로 만들 필요가 없습니다.

## 두 서비스 한눈에 비교

| | ChatGPT | Claude |
|---|---|---|
| 만든 곳 | OpenAI | Anthropic |
| 주소 | `chatgpt.com` | `claude.ai` |
| 이 과정에서 | 무료 계정 (사용량 제한 있음) | **기관 Team 계정** (유료, 초대 수락) |
| 잘하는 일 (경험적) | 이미지 생성, 웹 검색, 음성 대화 등 다양한 기능 | 긴 문서 읽기, 자연스러운 글쓰기, 코드·문서 작성 |
| 자료 묶음 기능 | **프로젝트** | **프로젝트** |

> 💡 강사 멘트: "어느 쪽이 더 좋다"보다 **같은 질문을 둘 다에 던져 비교**하는 습관을 들이게 합니다. 모듈 3에서 직접 비교합니다.

---

## 2-1. ChatGPT 가입 (약 5분)

1. 주소창에 `chatgpt.com` 입력
2. **[회원 가입]** (또는 Sign up) 클릭
3. **[Google로 계속하기]** → "업무" 계정 선택 → [계속]
4. 이름, 생년월일 등 기본 정보 입력 → [동의]
5. 처음 나오는 안내 창은 읽고 [확인] 또는 [다음]

**✅ 성공 확인:** 가운데에 "무엇을 도와드릴까요?" 같은 입력창이 보이면 완료

**화면 둘러보기 (강사가 짚어 줄 곳)**
- **가운데 입력창**: 질문 입력. 왼쪽의 **[+]** 버튼으로 파일 첨부
- **왼쪽 사이드바**: 지난 대화 목록, **새 채팅**, **프로젝트**
- **오른쪽 위/왼쪽 아래 프로필**: 설정 → 언어, 개인 맞춤 설정

## 2-2. Claude 가입 (약 5분)

이 과정은 기관이 준비한 **Claude Team(유료)** 계정을 씁니다. 따로 가입하지 않고 **초대를 수락**합니다.

1. 담당자에게 **업무 구글 계정 이메일**을 알려 줍니다 (사전 과제 안내의 제출 방법대로)
2. 며칠 안에 그 메일함으로 **Claude(Anthropic) 초대 메일**이 옵니다 → **[초대 수락]** (Accept invite)
3. **[Google로 계속하기]** → **초대받은 그 "업무" 계정** 선택
4. 이름(부르는 이름) 입력, 약관 동의. 화면에 따라 **휴대폰 번호 인증**이 나올 수 있습니다

**✅ 성공 확인:** 왼쪽 아래 프로필에 **기관 Team 이름**이 보이고, 가운데 입력창이 보이면 완료

> ⚠️ 초대받지 않은 다른 구글 계정으로 로그인하면 **무료 개인 화면**이 나옵니다. 이미 개인 Claude 계정이 있던 분은 왼쪽 아래 프로필 메뉴에서 **Team 쪽을 골라** 주세요.
> 초대 메일이 안 보이면 **스팸함·프로모션함**을 확인하고, 그래도 없으면 담당자에게 다시 보내 달라고 하세요.

**화면 둘러보기**
- **입력창의 [+] 버튼**: 파일·사진 첨부
- **왼쪽 사이드바**: 대화 목록(Chats), **프로젝트(Projects)**
- **왼쪽 아래 프로필**: 설정 → 언어, 개인 선호(답변 스타일)

## 2-3. 첫 대화로 손 풀기 (5분)

두 서비스에 **똑같이** 입력해 보고 답을 비교합니다.

```
안녕! 나는 오늘 처음 생성형 AI를 써 보는 사람이야.
너는 무엇을 잘하고, 무엇을 조심해서 써야 하는지 초등학생도 알 수 있게 5줄로 알려줘.
```

> 💡 ChatGPT는 무료, Claude는 Team(유료)이라 두 화면의 메뉴가 조금 다를 수 있습니다. Team 계정은 사용량이 넉넉하고, 스킬(06)과 Claude Code(12)를 모두 쓸 수 있습니다.

## Claude 요금제 비교: 무료 · Pro · Team

이 과정은 **Team**으로 진행하지만, 수업이 끝난 뒤 개인 계정으로 계속 쓸 때를 위해 차이를 알아 둡니다. (2026년 10월 `claude.com/pricing` 기준, 바뀔 수 있음)

| 기능 | 무료 | Pro (개인 유료) | **Team (이 과정)** | 이 과정에서 쓰는 곳 |
|---|---|---|---|---|
| 요금 | 0원 | 월 $20 | 1인 월 $25 (2명부터) | |
| 사용량 | 기본 | 무료보다 많음 | 넉넉함 (좌석 종류에 따라 다름) | 전 과정 |
| 채팅 · 파일 첨부 · 웹 검색 | ✅ | ✅ | ✅ | 03 |
| 미리보기 화면(아티팩트) · 코드 실행 · 파일 만들기 | ✅ | ✅ | ✅ | 07 |
| 프로젝트 | 최대 5개 | ✅ | ✅ + **팀 공유** | 03 |
| 스킬 | ✅ | ✅ | ✅ + **조직 전체 배포** | 06 |
| 기억(메모리) · 시크릿 채팅 | ✅ | ✅ | ✅ | |
| 쓸 수 있는 모델 | Sonnet · Haiku | + Opus 등 상위 모델 | + Opus 등 상위 모델 | |
| Research (심층 조사) | ❌ | ✅ | ✅ | |
| **Claude Code** | ❌ | ✅ | ✅ | **12** |
| Chrome · Microsoft 365 연동, 작업 예약 | ❌ | ✅ | ✅ | |
| 관리자 기능 (멤버 초대, 중앙 결제, 사용 분석, SSO) | ❌ | ❌ | ✅ | 수업 준비 |
| 대화 내용의 모델 학습 | 설정에서 선택 | 설정에서 선택 | 기업용 약관으로 기본적으로 쓰지 않음 | |

**정리하면**
- **무료로도** 이 과정의 03~07(채팅, 프로젝트 5개, 스킬, 미리보기)은 대부분 해 볼 수 있습니다. 다만 사용량이 적어 실습이 몰리면 한도에 걸리기 쉽습니다.
- **Claude Code(12)** 는 유료(Pro 이상)부터 됩니다.
- **Team** 은 Pro 기능에 **함께 쓰는 기능**(프로젝트 공유, 스킬 일괄 배포)과 **관리 기능**이 더해진 것입니다. 기관 교육·부서 단위로 쓸 때 맞는 요금제입니다.

## 수업에서 꼭 짚을 주의사항

- **AI는 틀릴 수 있습니다.** 숫자, 법령, 날짜, 사람 이름은 반드시 원문으로 확인합니다.
- **민감정보를 넣지 않습니다.** 주민번호, 환자·민원인 정보, 내부 기밀 문서는 업로드 금지. 소속 기관의 AI 사용 지침이 있다면 그것이 우선입니다.
- 설정에서 **대화 내용을 모델 학습에 쓰지 않도록** 하는 옵션이 있는지 함께 확인합니다. (메뉴 위치는 서비스 업데이트에 따라 바뀔 수 있습니다)

## 자주 막히는 곳

| 상황 | 해결 |
|---|---|
| 엉뚱한 Google 계정으로 가입됨 | 오른쪽 위 Chrome 프로필이 "업무"인지 먼저 확인. 이미 가입했다면 로그아웃 후 다시 |
| Claude 휴대폰 인증 실패 | 번호 형식 확인, 잠시 후 재시도 |
| Claude 초대 메일이 없음 | 스팸함 확인 → 담당자에게 재초대 요청. 제출한 이메일에 오타가 없는지 확인 |
| Claude 화면에 Team 이름이 안 보임 | 초대받지 않은 계정으로 로그인한 것. 로그아웃 후 초대받은 업무 계정으로, 또는 프로필 메뉴에서 Team 선택 |
| 화면이 영어로 나옴 | 설정에서 언어를 한국어로 변경 (또는 그냥 한국어로 질문해도 한국어로 답합니다) |
