## AI에게 건네는 것의 단계

| 단계 | 무엇을 건네나 | 얼마나 오래 쓰나 | 비유 | 배운 곳 |
|---|---|---|---|---|
| 프롬프트 | 이번 지시 | 대화 한 번 | 구두 지시 | 모듈 3, 5 |
| 파일 건네기 | 참고 자료 | 대화 한 번 | 서류 첨부 | 모듈 3 |
| 프로젝트(폴더) | 지침 + 자료 묶음 | 그 프로젝트 안에서 | 담당자 전용 서류함 | 모듈 3 |
| **스킬** | **일하는 방법 자체** | **어느 대화에서든. 필요할 때 AI가 알아서 꺼냄** | **업무 매뉴얼(SOP)** | **이번 모듈** |

## 6-1. 스킬은 어떻게 생겼나 (5분)

스킬은 **폴더 하나**입니다. 그 안에 `SKILL.md` 라는 Markdown 파일이 꼭 있어야 합니다.

```
📁 prd-interview          ← 스킬 폴더 (이름 = 스킬 이름)
 └─ 📄 SKILL.md           ← 필수. 이름, 언제 쓰는지, 일하는 순서
```

`SKILL.md` 는 두 부분입니다.

```markdown
---
name: prd-interview
description: 사용자가 새 업무 도구를 기획하거나 "PRD 써 줘"라고 할 때 사용한다. ...
---

# PRD 인터뷰
1. 한 번에 질문은 1~2개만 한다.
2. ...
```

| 부분 | 무엇을 쓰나 |
|---|---|
| **위쪽 `---` 사이** | `name`: 스킬 이름 (영문 소문자·숫자·하이픈) · `description`: 무엇을 하고 **언제** 쓰는지 |
| **아래쪽 본문** | 일하는 순서, 양식, 지킬 것 (모듈 3의 프롬프트를 문서로 적은 것) |

> 💡 AI는 `description` 을 보고 스킬을 꺼낼지 판단합니다. **"언제"가 빠지면 스킬이 동작하지 않습니다.** 직접 쓸 필요는 없습니다. 6-3부터는 Claude가 써 줍니다.

> 🧑‍🏫 비유: 프롬프트가 **구두 지시**라면, 스킬은 **업무 매뉴얼을 책꽂이에 꽂아 두는 것**입니다. 표지(`description`)에 "언제 보는 매뉴얼인지"가 적혀 있어야 AI가 필요할 때 꺼내 봅니다.

## 6-2. 만들어 둔 스킬 등록하고 써 보기 (10분)

모듈 5의 긴 **PRD 인터뷰 프롬프트**를 스킬로 만들어 두었습니다. 받아서 등록만 합니다.

1. 이 모듈 실습 파일에서 **PRD 인터뷰 스킬 (ZIP)** 내려받기 (압축을 풀지 않습니다)
2. Claude 왼쪽 아래 프로필 → **설정** → **기능(Capabilities)** → **스킬(Skills)**
   - 코드 실행·파일 만들기 같은 기능을 먼저 켜야 스킬 메뉴가 보이는 경우가 있습니다
3. **[스킬 업로드]** → `prd-interview.zip` 선택 → 목록에서 **켜기**
4. **새 대화**에서 아무 설명 없이 입력:

```
교육 일정을 한눈에 관리하는 도구를 기획하고 싶어
```

5. Claude가 스킬을 꺼내 쓰면 화면에 스킬 사용 표시가 나오고, **질문을 1~2개씩** 하기 시작합니다 ✅

> 🧑‍🏫 모듈 5에서는 긴 프롬프트를 붙여넣어야 했습니다. 스킬이 있으면 **한 문장**이면 됩니다. 모듈 5의 대화 화면과 지금 화면을 나란히 보여 주세요. "같은 인터뷰가 시작되는데, 내가 건넨 것은 한 문장뿐"이 이 모듈의 핵심 장면입니다.

## 6-3. Claude에게 스킬을 만들어 달라고 하기 (10분)

스킬도 AI가 만들어 줍니다. 과정이 끝날 때마다 쓰는 **강의평가 결과보고서**를 예로 해 봅니다.

```
과정이 끝날 때마다 쓰는 "강의평가 결과보고서"를 우리 양식으로 써 주는 스킬을 만들어 줘.
양식: 제목 / 1. 개요(과정·기간·응답률) / 2. 결과 요약(전체 평균) /
      3. 개선 필요 과목(평균 3.5 미만, 표) / 4. 주요 의견 / 5. 조치 계획(표)
- name은 eval-report
- description에 "언제 쓰는지"를 꼭 넣어 줘
- 자료에 없는 숫자나 조치 일정은 [확인 필요]로 표시하게 해 줘
- 바로 올릴 수 있게 eval-report 폴더째 ZIP 파일로 만들어 줘
```

1. Claude가 만든 **`eval-report.zip`** 내려받기
2. 6-2와 같은 방법으로 **[스킬 업로드]** → 켜기
3. 새 대화에서 한 문장으로 불러 보기: `제12기 강의평가 결과보고서 써 줘` → 숫자가 없으니 **[확인 필요]** 가 표시되면 정상

이 스킬은 모듈 7의 결재 보고서 실습과, 실제 과정이 끝날 때마다 쓰는 결과보고서에 그대로 쓸 수 있습니다.

> 🧑‍🏫 ZIP 파일이 나오지 않으면 "eval-report 폴더 안에 SKILL.md를 넣어 ZIP으로 내려받게 해 줘"라고 한 번 더 시킵니다. 그래도 안 되면 SKILL.md 내용을 복사해 아래 "참고" 방법(프로젝트 지침)으로 씁니다.

## 6-4. 내 업무 스킬 만들기 (15분)

6-3과 같은 방법으로 **내 업무**의 스킬을 하나 만듭니다. 매번 같은 양식으로 쓰는 보고서, 안내문, 공문 초안이 가장 좋은 대상입니다.

```
내가 매번 같은 양식으로 쓰는 "[문서 이름]"을 우리 양식으로 써 주는 스킬을 만들어 줘.
양식: [제목 / 1. ○○ / 2. ○○ / 3. ○○ 처럼 내 양식의 칸을 적기]
- name은 영문 소문자와 하이픈으로 (예: weekly-report)
- description에 "언제 쓰는지"를 꼭 넣어 줘
- 자료에 없는 숫자나 날짜는 [확인 필요]로 표시하게 해 줘
- 바로 올릴 수 있게 폴더째 ZIP 파일로 만들어 줘
```

1. ZIP 내려받기 → **[스킬 업로드]** → 켜기
2. 새 대화에서 **한 문장으로** 불러 보기: 예) `이번 주 주간 업무보고 써 줘`
3. (보관) ZIP을 풀어 나온 폴더를 옵시디언 보관소 `98_스킬` 폴더에 넣어 둡니다. 나중에 고칠 때 씁니다.

> 🧑‍🏫 떠오르는 문서가 없는 교육생에게는 "지난달에 두 번 이상 쓴 문서"를 떠올리게 하세요. 실제 내용 대신 예시 내용으로 시험하게 합니다. 오늘 만든 스킬이 수업 뒤에 가장 오래 쓰일 결과물입니다.

### 참고: 무료 계정이라면 같은 파일을 다르게 건네기

| 방법 | 하는 법 |
|---|---|
| **프로젝트 지침으로** | 모듈 3에서 만든 프로젝트의 지침 칸에 SKILL.md 본문(아래쪽)을 붙여넣기 → 그 프로젝트 안에서 한 문장으로 요청 |
| **파일로 첨부** | 새 대화에 SKILL.md를 첨부하고 "이 파일의 방법대로 진행해 줘" |

> 차이점: 스킬은 **어느 대화에서든 AI가 알아서** 꺼내고, 무료 방법은 **내가 건네야** 합니다.

## 좋은 스킬 체크리스트

```
□ description에 "무엇을"과 "언제"가 모두 있다
□ 스킬 하나에 일 하나 (PRD 인터뷰 + 보고서 작성을 한 스킬에 섞지 않기)
□ 순서가 번호로 적혀 있다
□ "지어내지 말 것([확인 필요])" 같은 지킬 것이 있다
□ 개인정보·비밀번호·내부 기밀이 들어 있지 않다
```

## 자주 막히는 곳

| 상황 | 해결 |
|---|---|
| 설정에 스킬 메뉴가 없음 | Team 화면이 맞는지(왼쪽 아래 Team 이름) 확인 → 맞으면 관리자 설정에서 스킬이 꺼져 있는 것. 당장은 "참고" 방법(프로젝트 지침·첨부)으로 진행 |
| 업로드하면 형식 오류 | ZIP 안에 **폴더째** 들어 있는지, 파일 이름이 정확히 `SKILL.md` 인지 확인. 안 되면 Claude에게 "업로드 형식 오류가 나. 다시 만들어 줘" |
| `name` 오류 | 영문 소문자·숫자·하이픈만. 한글이나 띄어쓰기 불가 |
| 새 대화에서 스킬이 안 나옴 | 목록에서 스킬이 **켜짐**인지, `description` 에 "언제 쓰는지"가 있는지 확인. "PRD 인터뷰 스킬로 진행해 줘"라고 직접 불러도 됨 |

## ✅ 확인 질문 (인터뷰)

1. 프롬프트, 프로젝트, 스킬의 차이를 한 줄씩 말해 볼까요? (구두 지시 / 서류함 / 업무 매뉴얼)
2. `description` 에 **"언제"** 를 꼭 써야 하는 이유는? (정답: AI가 그 문장을 보고 스킬을 꺼낼지 판단하므로)
3. 내 업무 중 **세 번 이상 같은 지시를 한 일**은 무엇인가요? 그것이 다음 스킬 후보입니다.
