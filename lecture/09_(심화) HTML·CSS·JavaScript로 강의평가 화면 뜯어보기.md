# 모듈 09 (심화 1). HTML · CSS · JavaScript로 강의평가 화면 뜯어보기

← [[08_AI 브라우저 Aside로 코딩 없이 업무 자동화]] | 다음 → [[10_(심화) 프로토타입 배포]]

모듈 7에서 Claude가 강의평가 집계 화면을 만들어 줬고, 모듈 8에서는 AI 브라우저가 그 화면을 대신 조작했습니다. 하지만 맞는 도구가 없으면 직접 만들어야 합니다. 배포하기 전에, 그 화면이 **어떤 재료로 어떤 순서로** 만들어지는지 열어 봅니다. 코드를 외우는 시간이 아닙니다. **읽고, 한 군데 바꿔 보고, 바뀐 결과를 눈으로 확인**하는 시간입니다.

## 웹 화면을 만드는 세 가지 재료

| 재료 | 하는 일 | 집으로 치면 | 사람으로 치면 | 강의평가 화면에서 |
|---|---|---|---|---|
| **HTML** | 화면에 **무엇이** 있는지 | 골조·벽·문 | 뼈대 | 제목, 입력칸, 버튼, 결과표 |
| **CSS** | **어떻게** 보이는지 | 페인트·인테리어 | 옷 | 배경색, 빨간 버튼, 표 구분선 |
| **JavaScript** | 눌렀을 때 **무엇을 하는지** | 전기·수도 | 근육 | 평균 계산, 개선 필요 판정 |

```
 1단계 HTML        2단계 + CSS        3단계 + JavaScript     4단계 완성본
 ┌──────────┐     ┌──────────┐      ┌──────────┐          ┌──────────┐
 │ 뼈대만    │ ─▶ │ 옷을 입힘 │ ─▶  │ 움직임    │   ─▶     │ 기억·편의 │
 │ 글자 나열 │     │ 색·배치   │      │ 평균 계산 │          │ 저장·취소 │
 └──────────┘     └──────────┘      └──────────┘          └──────────┘
                                                                 │
                                       모듈 10: 이 파일을 웹에 공개 ◀┘
```

## 1단계: HTML = 뼈대 (15분)

`1-html.html` 을 Chrome으로 엽니다. 색도 배치도 없이 **글자만 나열**되어 있습니다. 정상입니다.

### 코드 읽기

메모장으로 열어 보면 `<이름>내용</이름>` 모양이 반복됩니다. 이것을 **태그**라고 합니다.

| 태그 | 뜻 | 강의평가 화면에서 |
|---|---|---|
| `<h1>` | 가장 큰 제목 | 강의평가 결과 집계 |
| `<p>` | 문단 | 과정 안내 문장 |
| `<form>` | 입력 묶음 | 과목·교관·만족도·버튼을 감싼 상자 |
| `<label>` `<input>` | 이름표와 입력칸 | 과목 [____] |
| `<select>` `<option>` | 골라 넣는 칸과 보기 | 만족도 [5 매우 만족 ▼] |
| `<button>` | 버튼 | 평가 제출 |
| `<table>` `<tr>` `<td>` | 표, 표의 한 줄, 칸 하나 | 결과표 |
| `<!-- -->` | 메모(화면에 안 보임) | 코드 설명 |

> 💡 모듈 4의 Markdown과 비교해 보세요. Markdown의 `#` 이 HTML의 `<h1>`, `| 칸 | 칸 |` 이 `<tr><td>` 입니다. **구조를 표시한다**는 생각은 같습니다.

### 바꿔 보기

1. `<h1>강의평가 결과 집계</h1>` 를 `<h1>제12기 강의평가 결과</h1>` 로 → Ctrl + S → F5
2. 결과표에 한 줄 추가: `<tr><td>소방 관계법규</td><td>최교관</td><td>2</td><td>2.5</td><td>개선 필요</td></tr>`
3. **[평가 제출]** 을 눌러 보기 → 아무 일도 안 일어나고 페이지만 새로 뜹니다

> 🧑‍🏫 3번이 중요한 질문입니다. "왜 아무 일도 안 일어날까요?" → HTML은 **뼈대**라서 움직일 근육이 없습니다. 결과표의 평균도 사람이 미리 계산해 적어 둔 **글자**일 뿐입니다. 지금 네이버 폼 결과를 엑셀로 내려받아 평균을 계산해 적어 넣는 일과 똑같습니다.

## 2단계: CSS = 옷 (15분)

`2-css.html` 을 열어 1단계와 **나란히** 비교합니다. 같은 내용인데 업무 화면처럼 보입니다.

### 코드 읽기

HTML은 거의 그대로이고, 위쪽 `<style>` 안에 규칙이 추가됐습니다. 규칙 모양은 하나뿐입니다.

```css
대상 { 속성: 값; }

button {
  background: #c8321e;   /* 버튼 배경을 소방 적색으로 */
  color: white;          /* 글자는 흰색 */
}
```

| 대상 쓰는 법 | 뜻 | 예 |
|---|---|---|
| `button` | 모든 버튼 | 평가 제출 버튼 |
| `.bad` | `class="bad"` 가 붙은 것 | "개선 필요" 글자 |
| `.num` | `class="num"` 이 붙은 것 | 응답·평균 숫자 칸 (오른쪽 정렬) |
| `.wrap` | `class="wrap"` 이 붙은 것 | 가운데 기둥 |

### 바꿔 보기

1. 버튼 색: `background: #c8321e;` → `background: navy;`
2. 개선 필요 색: `.bad { color: #c8321e; ...}` 의 색을 `purple` 로
3. 기둥 너비: `.wrap` 의 `max-width: 520px;` → `300px` (좁아지는 것 확인)

### 🔍 개발자 도구로 남의 화면 들여다보기

Chrome에서 **F12** → 왼쪽 위 **화살표 아이콘** → 평가 제출 버튼 클릭 → 오른쪽 **Styles** 에서 `background` 값을 클릭해 바꿔 보기

> 🧑‍🏫 F5를 누르면 원래대로 돌아옵니다. 개발자 도구는 **내 화면에서만** 잠깐 바꿔 보는 연습장입니다. 아무 웹사이트에서나 해 볼 수 있어서, "모든 웹 화면이 HTML + CSS로 되어 있다"를 체감시키기 좋습니다.

## 3단계: JavaScript = 근육 (15분)

`3-js.html` 을 엽니다. 이번엔 **결과표가 비어** 있습니다. 과목·교관·만족도를 넣고 **[평가 제출]** → 결과표에 한 줄이 생깁니다. 같은 과목·교관으로 한 번 더 내면 **응답 수와 평균이 저절로** 바뀝니다. 처음으로 화면이 **계산을 했습니다.**

### 코드 읽기

맨 아래 `<script>` 안이 JavaScript입니다. 주석(`//`)을 따라 다섯 부분으로 읽습니다.

| 부분 | 하는 일 | PRD와 연결 |
|---|---|---|
| ① 화면 요소 찾기 | id로 입력칸·결과표를 찾아 둠 | |
| ② `answers` | 제출된 응답을 모아 두는 상자 | "평가 입력" |
| ③ `needsImprovement()` | 평균이 3.5보다 낮으면 개선 필요 | "평균 3.5 미만이면 개선 필요" |
| ④ `drawTable()` | **과목 + 교관**이 같은 응답끼리 묶어 응답 수·평균 계산 | "과목·교관별 집계" (v0.3) |
| ⑤ 버튼을 누르면 | 빈칸 검사 → 상자에 넣기 → 표 다시 그리기 | "점수 검사", 화면 흐름 |

> 💡 ③번을 보세요. PRD에 한국어로 쓴 규칙 "평균 3.5 미만이면 개선 필요"가 코드에서는 `avg < 3.5` 한 줄입니다. **PRD를 코드로 옮기는 것**, 그게 프로그래밍입니다.
>
> ④번의 `a.subject + " / " + a.instructor` 가 모듈 5에서 고친 구멍입니다. 여기서 `+ " / " + a.instructor` 를 지우면 교관이 섞여 다시 "평균 4.0, 양호"가 됩니다. **직접 지워 보고** 결과표가 어떻게 바뀌는지 확인하면 PRD 한 줄의 무게가 실감 납니다.

### 바꿔 보기

1. 개선 필요 기준: `return avg < 3.5;` → `3.0`
2. 오류 문구: `"과목, 교관, 만족도를 모두 입력하세요."` 를 원하는 말로
3. 평가 몇 건 제출 → **F5** → 결과표가 **사라집니다**

> 🧑‍🏫 3번에서 질문합니다. "왜 사라졌을까요?" → 응답을 **기억해 둘 곳이 없기** 때문입니다. 화면에 잠깐 계산해 그렸을 뿐입니다. 그래서 4단계가 필요합니다.

## 4단계: 완성본 = 기억과 편의 (함께 보기, 5분)

`index.html` (모듈 7에서 Claude가 만든 것과 같은 기능)을 열고, 3단계에서 **무엇이 더해졌는지** 확인합니다.

| 더해진 것 | 3단계의 문제 | 완성본 |
|---|---|---|
| **저장** | F5 하면 사라짐 | 브라우저 저장소(localStorage)에 기억 |
| **요약 숫자** | 응답 수만 | 응답 / 평가 과목 / 개선 필요 |
| **정렬** | 입력한 순서대로 | 평균이 **낮은 것부터** (보고서에 쓸 순서) |
| **예시 데이터** | 처음엔 빈 화면 | 처음 열면 "(예시)" 과목 10건 |
| **취소·초기화** | 잘못 내면 끝 | 마지막 응답 취소, 두 번 눌러 초기화 |
| **결과 내려받기** | 엑셀에서 보고서용 표로 다시 정리 | 엑셀에서 열리는 CSV |

> 🧑‍🏫 다리 놓기: 완성본도 **이 브라우저에만** 기억합니다. 교육생 40명이 각자 휴대폰으로 내면 40개의 브라우저에 흩어집니다. 배포(10)에서 직접 확인하고, 한곳에 모으는 방법(공용 장부)은 개념으로 짚습니다.

## 더 알아보기: JavaScript가 할 수 있는 일 10가지 (쉬는 시간·집에서)

세 재료 중 화면을 **살아 움직이게** 하는 것은 JavaScript입니다. 공통점은 **새로고침 없이 그 자리에서 바로 바뀐다**는 것입니다.

| 번호 | 예시 | JavaScript가 하는 일 | 업무에서 쓰면 |
|---|---|---|---|
| 1 | 계산하기 | 입력값을 읽어 계산하고 결과를 표시 | 강의평가 평균 계산 |
| 2 | 입력값 검사 | 입력 형식이 맞는지 실시간으로 판단 | 전화번호·날짜 형식 확인 |
| 3 | 실시간 시계 | 1초마다 화면을 다시 그림 | 시험 남은 시간 표시 |
| 4 | 다크 모드 | 버튼 하나로 모양을 통째로 바꿈 | 야간 상황실 화면 |
| 5 | 할 일 목록 | 화면 요소를 새로 만들고 지움 | 점검 체크리스트 |
| 6 | 글자 수 세기 | 입력 길이를 세고 기준을 넘으면 경고 | 공문 제목 글자 수 |
| 7 | 무작위 색 | 난수를 만들어 화면에 적용 | 발표 순서 뽑기 |
| 8 | 접고 펴는 안내문 | 누르면 내용을 보이거나 숨김 | 자주 묻는 질문 |
| 9 | 목록 검색 | 많은 자료에서 조건에 맞는 것만 거름 | 교육생 명단 찾기 |
| 10 | 퀴즈 채점 | 답을 판단하고 점수를 쌓음 | 복습 문제 |

직접 눌러 보고 싶으면 Claude에게 이렇게 시킵니다.

```
HTML, CSS, JavaScript 중 JavaScript가 할 수 있는 일을 10가지 예시로 보여 줘.
계산하기, 입력값 검사, 실시간 시계, 다크 모드, 할 일 목록, 글자 수 세기,
무작위 색, 접고 펴는 안내문, 목록 검색, 퀴즈 채점을
한 화면에서 직접 눌러 볼 수 있게 HTML 파일 하나로 만들어 줘.
예시마다 "JavaScript가 한 일"을 한 줄로 적고, 외부 라이브러리 없이.
```

### 파일 하나로 끝나는 것과 인터넷이 필요한 것

AI에게 "3D로 방 꾸미기를 만들어 줘"처럼 어려운 화면을 시키면, 남이 만든 **외부 라이브러리**(예: 3D용 three.js)를 인터넷에서 불러오는 코드를 쓰기도 합니다.

| | 파일 하나로 끝나는 화면 | 외부 라이브러리를 쓰는 화면 |
|---|---|---|
| 인터넷 | 없어도 열림 | 있어야 열림 (라이브러리를 받아 옴) |
| 행정망 | 대부분 그대로 열림 | 라이브러리 주소가 막히면 **빈 화면** |
| 이 과정의 프롬프트 | "외부 라이브러리 없이"를 넣음 | 필요할 때만, 열리는지 확인하고 씀 |

라이브러리를 **파일 안에 통째로 넣는** 방법도 있습니다. 아래 3D 방 꾸미기 완성 예시가 그렇게 만들어져 있어서, 파일은 커지지만(약 600KB) 인터넷 없이 더블클릭만으로 열립니다.

그래서 이 과정의 프롬프트에는 **"외부 라이브러리 없이, 파일 하나로"** 를 넣습니다. 화면이 하얗게 나오면 F12 → Console에 빨간 오류가 있는지 보고, 외부 주소를 불러오지 못한 것이면 "외부 라이브러리 없이 다시 만들어 줘"라고 시킵니다.

## 응용 실습: AI에게 큰 화면 맡기기 (시간이 남으면 · 과정 뒤, 20분)

강의평가 화면은 작은 화면입니다. 같은 세 재료로 **얼마나 큰 화면까지** 되는지 직접 시켜 봅니다. 둘 중 하나를 고르세요. 이 모듈 실습 파일에 두 화면의 **완성 예시**가 있으니, 먼저 열어 보고 시작해도 됩니다.

### A. 일정 플래너: 캘린더 + 간트차트 (Claude)

```
일정을 등록하면 월간 캘린더에, 프로젝트를 등록하면 간트차트에 보여 주는
일정 관리 화면을 HTML 파일 하나로 만들어 줘.
- 등록 창에서 "일정" / "프로젝트"를 고른다
- 일정: 제목, 날짜, 시작·종료 시간, 색, 메모 → 캘린더에 표시, 날짜를 누르면 그날 일정 목록
- 프로젝트: 제목, 시작일, 종료일, 진행률, 색 → 간트차트 막대, 끌어서 기간 이동·조절, 오늘 표시선
- 브라우저에 자동 저장, 삭제 후 되돌리기
- 부드러운 애니메이션, 깔끔한 디자인
- HTML·CSS·JavaScript만, 외부 라이브러리 없이
```

**만든 뒤 찾아볼 것**

| 화면에서 | 어느 재료가 한 일 |
|---|---|
| 캘린더 칸, 등록 창, 입력칸 | HTML (무엇이 있나) |
| 둥근 카드, 막대가 자라나는 움직임, 창이 커지며 열리는 효과 | CSS (어떻게 보이나) |
| 날짜 계산, 막대 끌기, 자동 저장, 삭제 되돌리기, 숫자 올라가는 효과 | JavaScript (어떻게 움직이나) |

- `F12` → **Application → Local Storage** 를 열면 저장된 일정이 글자로 보입니다. 완성본(4단계)과 같은 **"이 브라우저에만"** 저장입니다.
- 업무에 쓰면: 교육 일정, 과정 운영 일정, 시설 점검 일정. 실제 개인정보·내부 일정은 넣지 않습니다.

### B. 3D 방 꾸미기 (Claude)

```
3D로 방을 꾸미는 화면을 HTML 파일 하나로 만들어 줘.
- three.js 사용
- 바닥과 벽 두 면. 빈 곳을 끌면 방이 돌아가고, 휠로 확대·축소
- 가구 버튼(침대, 소파, 책상, 의자, 책장, 탁자, 화분, 스탠드, 러그)을 누르면 방에 놓이고, 끌어서 옮김 (벽 밖으로는 못 나감)
- 선택한 가구: 색 바꾸기, R 키로 돌리기, Delete 키로 지우기
- 벽 색, 바닥(마루·타일·단색), 낮·밤 바꾸기
- 브라우저에 저장, 사진(PNG)으로 저장
```

**만든 뒤 확인할 것**

- Claude 미리보기나 내려받은 파일이 **하얀 화면**이면 `F12` → **Console** 을 봅니다. three.js를 인터넷(`cdn.jsdelivr.net`, `cdnjs`, `unpkg` 등)에서 못 불러온 것이면 그 주소가 막힌 것입니다.
- 코드에서 `three` 가 들어간 `<script src="https://...">` 또는 `import` 줄을 찾아보세요. 이 한 줄이 **남이 만든 3D 도구를 빌려 오는 줄**입니다. 직접 쓰면 수만 줄인 3D 계산을 한 줄로 빌려 씁니다.
- 완성 예시 파일은 같은 도구를 파일 안에 넣어 두어 인터넷 없이 열립니다. **같은 기능, 다른 선택**입니다.

> 🧑‍🏫 8교시 50분은 1~4단계로 꽉 찹니다. 이 절은 시간이 남을 때만 하고, 아니면 완성 예시 두 개를 1분씩 띄워 보여 준 뒤 과정 뒤 과제(과제 안내 5번)로 넘깁니다. 큰 파일이라 만드는 데 1~3분 걸리고 중간에 끊길 수 있습니다("이어서 계속 써 줘"). 리허설 때 접속 점검 페이지의 "외부 라이브러리" 세 줄을 확인하고, 막혀 있으면 B는 완성 예시로만 보여 주고 교육생은 A를 고르게 합니다. 3D 완성 예시는 WebGL을 쓰므로 오래된 PC에서는 느릴 수 있습니다.

## 자주 막히는 곳

| 상황 | 해결 |
|---|---|
| 고쳤는데 화면이 그대로 | 메모장 **Ctrl + S** 를 했는지, Chrome **F5** 를 했는지 |
| 한글이 깨짐 | 메모장 저장 시 인코딩 **UTF-8** |
| 메모장 저장 후 `.txt` 가 붙음 | 파일 형식 **모든 파일**, 탐색기에서 확장자 표시 켜기 |
| 화면 일부가 통째로 사라짐 | 닫는 태그(`</td>`, `</tr>`, `</div>`)나 `}` 를 지운 것. 메모장 **Ctrl + Z** 로 되돌리기 |
| 3단계에서 버튼이 동작 안 함 | **F12 → Console** 의 빨간 오류 확인. 대부분 따옴표 `"` 나 괄호 `)` 가 빠진 것 |
| 어디를 고쳐야 할지 모름 | 메모장 **Ctrl + F** 로 화면에 보이는 글자를 검색 |
| AI가 만든 화면이 하얗게만 나옴 | 외부 라이브러리를 인터넷에서 못 불러온 것. "외부 라이브러리 없이 파일 하나로 다시 만들어 줘" (3D처럼 꼭 필요하면 완성 예시 파일로 봄) |
| AI의 답이 코드 중간에 끊김 | 긴 파일은 답 한 번에 다 못 쓸 수 있음. "이어서 계속 써 줘" 또는 [계속]. 무료 계정은 사용 한도가 차면 멈춤 |
