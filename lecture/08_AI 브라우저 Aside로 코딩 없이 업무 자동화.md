# 모듈 08. AI 브라우저 Aside로 코딩 없이 업무 자동화

← [[07_PRD로 결과물 만들기 (NotebookLM·생성형 AI)]] | 다음 → [[09_(심화) HTML·CSS·JavaScript로 강의평가 화면 뜯어보기]]

📌 **각자 강의장 PC에 Aside를 설치하고 가입한 뒤 직접 실습합니다.** 실습은 강의 사이트와 공개 사이트에서만 합니다.

> 🧑‍🏫 **리허설 전 모듈입니다.** 수업 전에 꼭 확인할 것
> - **설치 허용**: 강의장 PC 한 대로 `aside.com` 에서 설치 파일을 받아 설치까지 해 봅니다. 막히면 옵시디언(04)과 함께 정보화 담당에게 설치 허용(또는 사전 일괄 설치)을 요청합니다.
> - **무료 크레딧**: 무료 요금제(월 500크레딧)로 실습 1·2와 루틴 1개를 해 보고 크레딧이 얼마나 남는지 확인합니다. 부족하면 실습 1을 짝과 한 화면으로 진행합니다.
> - **보안 범위**: 행정망 PC에서 내부 업무 시스템, 메일, 개인정보 화면에는 로그인하지 않게 시작 전에 분명히 말합니다. 수업 후 프로그램을 지울지는 정보화 담당 안내를 따릅니다.
> - Aside의 화면·요금·기능은 2026년 10월 확인 기준이며 자주 바뀝니다. 메뉴 이름은 리허설 때 맞춰 주세요.

지금까지는 AI에게 **글과 파일**을 건네고 결과를 받았습니다(03~07). 스킬(06)로 일하는 방법도 맡겼습니다. 그런데 행정 업무의 상당 부분은 **웹사이트를 열고, 찾고, 누르고, 내려받는 일**입니다. 이번 모듈에서는 **코딩 없이** AI가 브라우저를 직접 조작해 그 일을 대신하게 해 봅니다.

## 업무 자동화의 세 단계

| 단계 | 무엇으로 | 이럴 때 | 모듈 |
|---|---|---|---|
| ① 방법을 맡긴다 | **스킬** (Markdown 매뉴얼) | 같은 양식의 글·보고서·문제를 반복해서 만들 때 | 06 |
| ② 클릭을 맡긴다 | **AI 브라우저** (Aside) | 이미 있는 웹사이트에서 찾기·입력·확인·내려받기를 반복할 때 | **08 (이번)** |
| ③ 도구를 만든다 | **코딩** (HTML → 배포 → 장부 → Claude Code) | 맞는 도구가 **없어서** 직접 만들어야 할 때 | 09 ~ 12 |

> 🧑‍🏫 핵심 멘트: "**코딩은 마지막 수단입니다.** 스킬이나 브라우저 자동화로 되는 일이면 그걸로 충분합니다. 그런데 강의평가 집계처럼 맞는 도구가 아예 없으면? 그때 직접 만듭니다. 그게 다음 시간부터 할 일입니다."

## Aside 한눈에 보기

- AI 에이전트가 들어 있는 **크롬 계열 브라우저**입니다. Mac과 **Windows**(2026년 9월부터)에서 쓸 수 있습니다.
- 내가 **로그인해 둔 사이트**에서 사람처럼 화면을 보고 클릭·입력합니다. 사이트마다 따로 연결 설정을 하지 않아도 됩니다.
- **루틴(Routine)**: 정해 둔 일을 반복해서 하게 할 수 있습니다. "매일 아침 ○○ 확인" 같은 자동화에 씁니다.
- **보안 장치**: 작업 기록과 기억은 내 PC에 저장하고, 내장 비밀번호 관리자는 비밀번호를 AI 모델에 보여 주지 않고 로그인합니다. 결제·게시·메시지 보내기 같은 **민감한 동작은 사람의 승인**을 기다립니다.
- **요금**: 무료 요금제(월 500크레딧, 루틴 3개), 유료 Pro(월 20달러), Max(월 200달러)

## 8-1. 설치와 가입 (15분)

모든 작업은 **파란 "업무" Chrome 프로필 창**에서 시작합니다.

1. Chrome 주소창에 `aside.com` → **Windows용 다운로드**
2. 받은 설치 파일 실행. "Windows의 PC 보호" 파란 창이 뜨면 **[추가 정보] → [실행]** (04 옵시디언 설치와 같습니다)
3. 설치가 끝나면 Aside가 열립니다. **[Google로 계속하기]** → **업무 계정**으로 로그인
4. 요금제는 **무료(Free)** 로 시작합니다. 카드 정보를 입력하라는 화면이 나오면 진행하지 말고 손을 들어 주세요
5. 기존 브라우저의 북마크·비밀번호를 **가져올지 물으면 가져오지 않습니다.** 이 실습에는 필요 없고, 업무 비밀번호를 새 프로그램에 옮기지 않는 것이 안전합니다

**✅ 성공 확인:** Aside 창에서 AI에게 말을 거는 입력창(사이드 패널)이 보이면 완료

> 🧑‍🏫 설치가 막힌 교육생은 옆 사람 화면으로 함께 진행합니다. 10분이 지나면 기다리지 말고 8-2로 넘어가세요.

## 8-2. 실습 1: 화면 조작 맡기기 (10분)

07에서 Claude가 만든 것과 같은 **강의평가 집계 화면**(강의 사이트에 올려 둔 예시)을 Aside에게 맡깁니다. 아래 지시를 Aside 입력창에 붙여넣으세요.

```
https://www.jg-sobang.com/fire-ai/prototype/index.html 을 열고
과목 "실습과목", 교관 "실습교관"으로 만족도 5, 3, 2 평가를 차례로 제출해 줘.
그다음 결과표에서 "개선 필요"로 표시된 과목과 교관, 평균을 모두 알려 주고,
결과 내려받기 버튼을 눌러 파일을 저장한 뒤 파일 이름을 알려 줘.
```

지켜볼 것:
- AI가 **화면을 보고** 입력칸을 찾아 글자를 넣고, 만족도를 고르고, 버튼을 누르는 모습
- 중간에 **허락을 묻는** 창이 나오면 무엇을 하려는지 **읽고 나서** 승인하기
- 마지막 보고가 **실제 화면과 같은지** 내 눈으로 확인하기 (예상: 실습과목·실습교관 평균 3.3 → 개선 필요)

> 🧑‍🏫 평가를 사람 대신 내게 하는 것은 **연습용**입니다. 실제 평가를 AI가 대신 내면 평가의 의미가 없어진다는 점을 짚고, 실무에서는 **찾기·확인·정리하는 쪽**에 맡긴다고 정리합니다(실습 2, 루틴).

## 8-3. 실습 2: 공개 사이트에서 찾아 정리하기 (10분)

06-5에서 문제출제 스킬이 "근거는 원문으로 확인"을 강조했습니다. 그 확인 작업을 브라우저에 맡겨 봅니다.

```
국가법령정보센터(law.go.kr)에서 "화재의 예방 및 안전관리에 관한 법률"을 찾아
현재 시행 중인 법률의 시행일을 알려 줘.
화면에서 확인한 문장을 그대로 인용하고, 어느 화면에서 찾았는지도 알려 줘.
```

> 결과를 그대로 믿지 않고 **AI가 보여 준 화면과 내가 직접 연 화면을 대조**합니다. "원문 대조"라는 습관은 스킬이든 브라우저든 같습니다.

## 8-4. 루틴으로 만들기 (5분)

```
평가 기간(9월 28일~10월 2일) 동안 매일 오후 4시에 강의평가 화면을 열어서
전체 응답 수와 "개선 필요" 과목·교관 목록을 확인하고, 결과를 세 줄로 정리해 줘.
```

이 지시를 **루틴**으로 저장해 봅니다(무료 요금제는 루틴 3개까지). 저장한 뒤에는 실습이 끝났으니 **꺼 두거나 지웁니다.**

> 루틴이 되면 담당자가 매일 열어 볼 필요가 없습니다. 응답이 적은 날은 참여 독려 문자(모듈 3의 안내문)를 보낼 때를 알려 주는 셈입니다. 스킬(06)이 "일하는 방법"을 적어 둔 것이라면, 루틴은 **"언제 할지"까지** 정해 둔 것입니다.
>
> 그런데 지금 이 화면은 **각자의 브라우저에만** 기록이 남습니다. 40명의 응답을 한곳에 모아야 루틴이 의미가 있습니다. 그래서 다음 모듈부터 화면을 직접 뜯어보고(09), 웹에 공개하고(10), 공용 장부를 붙입니다(11).

## 행정 업무에 쓸 때의 기준

| 질문 | 기준 |
|---|---|
| 어떤 사이트에서 써도 되나? | **기관 규정이 허용한 곳만.** 내부 업무 시스템, 개인정보가 있는 화면은 기본적으로 쓰지 않음 |
| 어떤 일을 맡기나? | 공개 정보 확인, 내가 만든 도구 점검처럼 **틀려도 되돌릴 수 있는 일**부터 |
| 승인은 누가? | 결제·게시·메시지 보내기·삭제는 **반드시 사람이 승인** |
| 결과는 믿어도 되나? | AI의 보고와 **실제 화면을 대조**. 숫자는 직접 확인 |

## 자주 막히는 곳

| 상황 | 해결 |
|---|---|
| 설치 파일이 실행되지 않음 | 기관 PC에서 설치가 막힌 것. 옆 사람 화면으로 함께 진행 |
| 로그인 창이 계속 다시 뜸 | 업무 계정으로 로그인했는지 확인. 팝업 창을 닫았다면 [Google로 계속하기]를 다시 |
| AI가 엉뚱한 곳을 누름 | 멈춤(정지) 버튼으로 세우고, 지시를 더 구체적으로 ("입력칸 '과목'에"처럼 화면에 보이는 글자를 그대로) |
| 크레딧이 부족하다는 안내 | 무료 크레딧을 다 쓴 것. 나머지는 옆 사람 화면으로 |
| 승인 창이 떴는데 무슨 뜻인지 모름 | 누르지 말고 손을 들어 주세요. 모르면 승인하지 않는 것이 원칙 |
