# 모듈 08 (심화 2). 프로토타입을 웹에 공개하기 (GitHub + Vercel)

← [[07_(심화) HTML·CSS·JavaScript로 출석부 뜯어보기]] | 다음 → [[09_(심화) Firebase로 공용 장부 연결]]

모듈 6에서 Claude로 만든 출석부 화면을 **누구나 휴대폰으로 여는 웹 주소**로 공개합니다. 설치 없이 **웹 브라우저만으로**, 비용 0원으로 진행합니다. 모든 작업은 **파란 "업무" Chrome 프로필 창**에서 합니다.

## 흐름과 낱말 4개

```
 index.html ──(올리기 = 커밋·푸시)──▶ GitHub 창고 ──(자동 연결)──▶ Vercel ──▶ https://내주소.vercel.app
 (내 컴퓨터)                           (기록·보관)                  (공개)     (누구나 접속)
```

| 낱말 | 한 줄 설명 | 비유 |
|---|---|---|
| **저장소 (Repository)** | 프로젝트 파일과 변경 기록을 담는 곳 | 프로젝트 상자 |
| **커밋 (Commit)** | 변경 내용을 **메모와 함께** 기록 | 저장 + 메모 |
| **푸시 (Push)** | 내 컴퓨터의 기록을 GitHub로 올림 | 택배 발송 |
| **배포 (Deploy)** | 웹 주소로 공개 | 가게 오픈 |

> 💡 웹 브라우저 방식에서는 GitHub 웹사이트에 파일을 올리는 순간 **커밋과 푸시가 한 번에** 일어납니다. 오늘은 "올리기 = 커밋 + 푸시"로 묶어 설명하고, Git 프로그램을 쓰면 둘이 나뉜다는 것만 한 줄로 예고합니다.

| 도구 | 하는 일 | 비유 |
|---|---|---|
| **GitHub** | 파일 보관 + 변경 기록. **고치는 곳** | 창고 + 변경 일지 |
| **Vercel** | GitHub의 파일을 웹 주소로 공개. **보여 주는 곳** | 진열대 |

---

## 0. 준비: `index.html` 파일 만들기 (5분)

웹사이트의 **대문 파일** 이름은 반드시 **`index.html`** 이어야 합니다.

**방법 1: Claude에서 내려받기** (다운로드 버튼이 보이면)
- 프로토타입 대화 → 미리보기 창 또는 코드 블록의 **다운로드** → 파일 이름을 `index.html` 로 변경

**방법 2: 메모장에 저장하기**
1. Claude 답변 코드 블록 오른쪽 위 **복사** → **메모장**에 **Ctrl + V**
2. **파일 → 다른 이름으로 저장**
   - 파일 이름: `index.html`
   - 파일 형식: **모든 파일 (\*.\*)** ← 중요
   - 인코딩: **UTF-8**
3. 저장 위치: `문서 > AI업무자료 > 03_AI결과물`

✅ 저장한 파일을 **더블클릭**해 Chrome에서 출석부가 열리면 준비 완료

> ⚠️ 가장 흔한 실수: 파일 형식을 "텍스트 문서"로 두면 `index.html.txt` 가 됩니다. 파일 탐색기 **[보기] → [파일 확장명]** 을 켜 두세요. 인코딩이 UTF-8이 아니면 한글이 깨집니다.
> 지난 시간 파일이 없는 수강생을 위해 완성본(`prototype-demo/index.html`)을 공유 링크로 준비해 두세요.

## 1. GitHub 계정 만들기 (10분)

1. `github.com` → **[Sign up]**
2. **[Continue with Google]** → **업무 계정** 선택 (버튼이 없으면 업무 Gmail로 이메일 가입 → 8자리 인증 코드)
3. **Username** 정하기 → 퍼즐 인증 → 설문 Skip → 요금제 **Free**
4. ✅ 오른쪽 위 프로필 아이콘을 누르면 내 Username이 보이면 완료

Username은 웹 주소에 그대로 들어갑니다: `https://github.com/hong-gildong`

| | Gmail 주소 | GitHub Username |
|---|---|---|
| 쓸 수 있는 글자 | 영문 소문자, 숫자, **마침표(.)** | 영문, 숫자, **하이픈(-)** |
| 예시 | `hong.gildong.work` | `hong-gildong` |

> ⚠️ Gmail과 규칙이 다릅니다. GitHub은 **마침표 대신 하이픈**을 씁니다.
> 시간이 지나면 **2단계 인증(2FA)** 설정을 요구합니다. 인증 앱으로 설정하고 **복구 코드는 반드시 따로 저장**하게 하세요.

## 2. 저장소 만들기 (5분)

1. 오른쪽 위 **[+]** → **[New repository]**
2. **Repository name**: `attendance-prototype` (웹 주소가 되므로 영문 + 하이픈)
3. **Public** 선택
4. **Add a README file** ✅ 체크
5. **[Create repository]**

| | Public (공개) | Private (비공개) |
|---|---|---|
| 누가 보나 | 누구나 | 나와 초대한 사람 |
| 오늘 실습 | ✅ | |
| 이럴 때 | 연습, 공개해도 되는 자료 | 업무 자료 |

> ⚠️ Public 저장소에는 **개인정보, 내부 문서, 비밀번호를 절대 올리지 않습니다.** 모듈 2의 "민감한 정보는 넣지 않는다"와 같은 원칙입니다.
> README 체크를 빼먹으면 명령어가 잔뜩 적힌 화면이 나옵니다. 그 화면의 **"uploading an existing file"** 링크로 3단계를 바로 진행하면 됩니다.
> README의 확장자도 **`.md`** 입니다. 모듈 4의 Markdown이 여기서도 쓰인다고 연결해 주세요.

## 3. 파일 올리기 = 커밋 + 푸시 (5분)

1. **[Add file]** → **[Upload files]**
2. `index.html` 을 점선 상자에 끌어다 놓기 (또는 **choose your files**)
3. **Commit changes** 칸에 메시지: `출석부 프로토타입 첫 업로드`
4. **[Commit changes]**
5. ✅ 파일 목록에 `README.md`, `index.html` 두 개
6. 시계 아이콘(또는 **"2 Commits"**)을 눌러 **변경 일지** 확인

```
● 출석부 프로토타입 첫 업로드      hong-gildong   방금 전
● Initial commit                  hong-gildong   5분 전
```

| ✗ 나쁜 커밋 메시지 | ✓ 좋은 커밋 메시지 |
|---|---|
| `수정`, `ㅇㅇ` | `지각 기준을 09:10으로 변경` |
| `최종`, `최종2`, `진짜최종` | `동명이인 대비 교육생 번호 입력칸 추가` |

> 🧑‍🏫 멘트: "`진짜최종2.hwp` 경험 있으시죠? 커밋을 쓰면 **파일은 하나**, 기록은 **전부** 남습니다."

## 4. Vercel 계정 만들기 (3분)

1. `vercel.com` → **[Sign Up]**
2. 플랜: **Hobby** (개인 프로젝트, 무료)
3. 이름 입력 → **[Continue with GitHub]** → **[Authorize Vercel]**

```
 Google 계정 ──▶ GitHub 가입   (모듈 1의 열쇠로)
 GitHub 계정 ──▶ Vercel 가입   (GitHub이 열쇠가 됨 → 처음부터 연결)
```

> ⚠️ **Pro**(유료)를 고르면 결제 정보 입력이 나옵니다. **Hobby**를 고르게 하세요. Hobby는 개인·비상업적 용도가 조건이므로, 기관의 정식 서비스로 운영할 때는 약관과 요금제를 따로 검토해야 합니다.

## 5. 배포하기 (5분)

1. 대시보드 **[Add New…]** → **[Project]**
2. **Import Git Repository** 목록에서 `attendance-prototype` → **[Import]**
3. 설정은 그대로 (Framework Preset: **Other**) → **[Deploy]**
4. 1분 내외로 🎉 축하 화면 → **[Continue to Dashboard]**

**목록에 저장소가 안 보이면** → 목록 아래 **Adjust GitHub App Permissions** (또는 [Install]) → **Only select repositories** → `attendance-prototype` 선택 → 저장

### 주소가 두 개입니다: 공유할 것은 **Domains**

| 화면 위치 | 예시 | 용도 |
|---|---|---|
| **Deployment** | `attendance-prototype-hmmzt68iw-…vercel.app` | 이번 배포 **한 건**만 가리킴. 보호 설정에 따라 **Vercel 로그인을 요구**할 수 있음 |
| **Domains** ✅ | `attendance-prototype-lyart.vercel.app` | 항상 **최신 배포**를 보여 주는 대표 주소. 수정해도 그대로 |

> ✅ **행정망 리허설 결과**: 강의장 행정망 PC에서 GitHub 저장소 만들기부터 Vercel 배포까지 확인했습니다.

### 📱 휴대폰으로 열기: QR 만들기

> 데스크톱 강의에서 QR은 **자료 배포용이 아니라 배포한 출석부를 수강생 휴대폰으로 확인하는 용도**입니다. 링크를 PC끼리 나눌 때는 PC 메신저나 메일을 씁니다.

배포된 **Domains 주소**를 Chrome에서 연 상태에서:

| 방법 | 하는 법 |
|---|---|
| ① 오른쪽 클릭 | 페이지 빈 곳 오른쪽 클릭 → **이 페이지의 QR 코드 생성** |
| ② 메뉴 | 오른쪽 위 **⋮** → **전송, 저장, 공유** → **QR 코드 만들기** |

- 휴대폰 카메라로 찍으면 열립니다. **[다운로드]** 로 이미지 저장도 가능 (메뉴 이름은 Chrome 버전에 따라 다를 수 있음)
- 수강생끼리 **QR을 교환**해 서로의 출석부에 출석해 보게 하면 반응이 좋습니다
- 예시 QR: [[실습자료/출석부_QR.png]]

> ⚠️ Deployment 주소로 QR을 만들면 다른 사람 휴대폰에서 **Vercel 로그인 화면**이 뜰 수 있습니다. "QR은 **Domains** 주소로"를 꼭 짚어 주세요.

## 6. 수정 → 커밋 → 자동 재배포 (5분)

**고치는 곳은 GitHub입니다.** Vercel에는 편집 기능이 없습니다. (리허설에서 실제로 나온 질문: "Vercel 화면에서 연필이 어디 있어요?")

**GitHub으로 가는 지름길**: Vercel 프로젝트 화면 **Production Deployment** 상자 오른쪽 위 버튼 중 **GitHub 고양이 아이콘**

```
[Open in ▾]  [ GitHub 아이콘 ]  [Instant Rollback]  [Visit ▾]
                   ▲
```

1. GitHub 저장소 → **`index.html`** 클릭
2. 코드 상자 오른쪽 위 회색 막대 끝의 **연필(✏️ Edit this file)** 클릭

```
┌──────────────────────────────────────────────────────────┐
│ Code   Blame   271 lines · 9.2 KB      [Raw] [⧉] [⤓] [✏️] [⋯] │ ← 여기
├──────────────────────────────────────────────────────────┤
```

   - 연필이 안 보이면 옆 **[⋯]** → **Edit file**. 파일 화면에서 키보드 **`e`** 를 눌러도 됩니다
   - 연필이 눌리지 않으면 GitHub 로그인이 풀린 것
3. **Ctrl + F** 로 `교육생 출석부` 를 찾아 `제13기 출석부` 로 변경
4. **[Commit changes…]** → 메시지 `제목을 제13기 출석부로 변경` → **[Commit changes]**
5. Vercel **Deployments** 메뉴에서 **새 배포가 저절로** 시작되는 것 확인 → **Ready**
6. 1~2분 뒤 휴대폰에서 **새로고침** → 같은 주소에 바뀐 제목

```
● 제목을 제13기 출석부로 변경        Building… → Ready     방금 전
● Add files via upload              Ready                  10분 전
```

> 🎯 핵심: **커밋만 하면 배포는 자동입니다.** Vercel 화면의 문장 *"To update your Production Deployment, push to the main branch."* 가 바로 이 뜻입니다.
> 고칠 때 `<`, `>`, `"` 같은 **기호는 건드리지 말고 한글 글자만** 바꾸게 하세요. 화면이 깨지면 **Instant Rollback**으로 이전 배포로 즉시 되돌리는 시연 기회로 씁니다.

> ⭐ **Pro 트랙 (선택)**: 손으로 제목을 고쳐 본 뒤, 같은 수정을 **Claude Code**(`claude.ai/code`)에게 말로 맡겨 봅니다. 예: "index.html의 제목을 제14기 출석부로 바꿔 줘". 자세한 방법은 [[10_(심화) Claude Code로 한 번에 만들고 배포하기]]. 시간이 부족하면 모듈 10에서 한꺼번에 합니다.

## 7. 마무리: 장부는 공유되지 않는다

수강생끼리 서로의 QR로 출석한 뒤 묻습니다. "짝꿍 휴대폰 명단에 내 이름이 보이나요?" → **안 보입니다.** 기록이 각자의 브라우저에만 저장되기 때문입니다.

```
 지금:     [내 휴대폰 장부]   [짝꿍 휴대폰 장부]   ← 따로따로
 다음 회차: [내 휴대폰] ─┐
            [짝꿍 휴대폰] ┼──▶ 데이터베이스 (공용 장부)  ← 모두가 같은 명단
            [교관 PC]   ─┘
```

다음 회차에서 **Firebase**(Google 서비스, 업무 Google 계정으로 시작)를 연결해 모두가 같은 명단을 보는 출석 시스템으로 만듭니다.

## 자주 막히는 곳

| 상황 | 해결 |
|---|---|
| `index.html.txt` 로 저장됨 | 메모장 저장 시 파일 형식 **모든 파일**, 탐색기에서 확장자 표시 켜기 |
| 한글이 깨짐 | 메모장 저장 시 인코딩 **UTF-8** |
| GitHub Username 빨간 글씨 | 마침표 대신 **하이픈(-)** |
| Vercel에서 저장소가 안 보임 | **Adjust GitHub App Permissions** 로 저장소 접근 허용 |
| 배포 주소가 404 | 파일 이름이 정확히 `index.html` 인지, 저장소 맨 위에 있는지 확인 |
| 다른 사람 휴대폰에서 Vercel 로그인 화면 | **Deployment** 주소를 공유함 → **Domains** 주소로 다시 공유 |
| 연필 아이콘이 없음 | Vercel이 아니라 **GitHub**에서 고칩니다 |
| 수정했는데 그대로 | 1~2분 대기 후 새로고침, Vercel **Deployments** 에서 Ready 확인 |
