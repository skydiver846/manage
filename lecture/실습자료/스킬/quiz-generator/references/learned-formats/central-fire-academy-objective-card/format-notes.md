# 양식 — 중앙소방학교 객관식 문제카드

- **원본 서식**: 중앙소방학교 평가관리규정 [별지 제4호서식] 객관식 문제카드 (A4, 8행×14열 표 1개짜리 단일 문항 카드)
- **레퍼런스 파일**: `reference.hwpx` — 원본 서식을 교육운영 실무에 맞게 다듬은 버전. 문항 카드를 만들 때는 `scripts/make_quiz_cards.py` 가 이 파일을 문항 수만큼 복제해 칸만 채운다. 표 구조·글꼴·테두리는 건드리지 않는다.

## 원본 서식과 다른 점

- **중요도(AㆍBㆍC) 칸 없음** — 표 2행에서 삭제하고, 난이도 값 칸과 출제근거 값 칸이 그 너비를 나눠 가짐
- **하단 용지규격 문구(210㎜×297㎜…) 없음**
- **문제·보기 칸은 왼쪽 정렬** — 글자가 번호(1~4) 칸 바로 옆에서 시작
- 과정명·과목명·출제근거 값 칸은 2줄 분량 높이
- 출제자 소속 칸에 기본값 없음 (5개 메타정보 칸 모두 공란)

## 칸 좌표와 채우는 값 (colAddr, rowAddr)

| 칸 | 좌표 | 채우는 값 |
|---|---|---|
| 과정명 | (1, 0) | 사용자에게 확인한 값 |
| 과목명 | (6, 0) | 사용자에게 확인한 값 |
| 정답 | (13, 0) | 보기 번호(1~4) |
| 난이도 | (1, 1) | "상ㆍ중ㆍ하" 중 실제 난이도만 【 】로. 예: 상ㆍ【중】ㆍ하 |
| 출제근거 | (11, 1) | 법령·교범명과 조·항 (4단계 검증을 거친 것만) |
| 문 번호 | (0, 2) | 문( 1 ) |
| 문제 | (1, 2) | 문제 문장 |
| 보기 1~4 | (1, 3) ~ (1, 6) | 보기 문장 |
| 출제일자 | (1, 7) | 사용자에게 확인한 값. 없으면 원래의 ".   .   . " 유지 |
| 출제자 소속 | (7, 7) | 사용자에게 확인한 값 |
| 성명 | (12, 7) | 이름 + 원래 있던 (인) 표시 글자 유지 |

## 작성 규칙

1. **출제 문항 수와, 과정명·과목명·출제일자·출제자 소속·성명 5개는 매번 사용자에게 확인한다.** 지난번 값이나 예시 값을 쓰지 않는다. 답이 없으면 빈 칸으로 두고 "확인 필요"라고 알린다.
2. **해설(근거·풀이)은 문제카드에 넣지 않는다.** 별도 정답지에 문항별로 쓴다 (`make_quiz_cards.py --answers`).
3. 표 구조·글자모양·테두리는 바꾸지 않는다. 공식 서식 변형이므로 내용(텍스트)만 채운다.
4. 문항마다 카드 한 장(한 페이지)이다.
