## 1. 배경·문제

- 현재 신임 교육생 출석을 **종이 명부에 수기로** 받고, 오후에 엑셀로 다시 옮겨 적는다.
- 아침 집합 시간(08:40~09:00)에 명부 앞에 줄이 생기고, 지각 여부를 담당자가 시계를 보고 따로 표시한다.
- 옮겨 적는 과정에서 누락·오기가 생긴다.

## 2. 목표

- 교육생이 **휴대폰에서 이름만 입력**해 출석을 마친다.
- 담당자는 화면 하나로 **출석 인원, 정시, 지각 인원**을 바로 확인한다.
- 이번 프로토타입의 목표: **실제 사용 흐름을 보여 주고 의견을 받는 것** (정식 시스템 아님)

## 3. 사용자

| 사용자 | 상황 | 원하는 것 |
|---|---|---|
| 교육생 (약 40명) | 아침 집합 시 휴대폰 사용 | 빠르게 출석하고 끝내기 |
| 교육운영 담당자 | 강당 앞, 노트북 또는 휴대폰 | 출석 현황을 한눈에 보기 |

## 4. 핵심 기능

| 우선순위 | 기능 | 설명 |
|---|---|---|
| 필수 | 출석 체크 | 이름과 교육생 번호(2자리) 입력 → [출석 체크] 버튼 → 현재 시각과 함께 기록 |
| 필수 | 정시/지각 판정 | **09:00 이후** 기록은 "지각", 이전은 "정시" 표시 |
| 필수 | 요약 숫자 | 출석 / 정시 / 지각 인원을 화면 위에 표시 |
| 필수 | 중복 방지 | 이름과 교육생 번호가 **모두 같을 때만** 안내 문구를 보여 주고 막기 (동명이인은 번호로 구분) |
| 있으면 좋음 | 기록 삭제 | 잘못 입력한 한 건을 지우기 |
| 있으면 좋음 | 전체 초기화 | 다음 날을 위해 전부 지우기 (실수 방지를 위해 두 번 눌러 확인) |

## 5. 화면·흐름

```
[화면 위] 과정명 · 날짜 · "09:00 이후 지각 처리" 안내
[요약]   출석 N | 정시 N | 지각 N
[입력]   교육생 이름 [__________]  번호 [__] [출석 체크]
[명단]   시각 | 이름 · 번호 | 정시/지각 | 삭제(×)
```

1. 교육생이 이름과 번호 입력 → [출석 체크]
2. 명단 맨 아래에 시각·이름·상태가 추가되고 요약 숫자가 바뀜
3. 이름이나 번호를 비우고 누르면 "이름과 교육생 번호(숫자 2자리)를 입력한 뒤 출석 체크를 누르세요." 안내
4. 처음 열었을 때는 **예시 데이터 3건**을 "(예시)" 표시와 함께 보여 줌

## 6. 범위 밖 (이번에 하지 않는 것)

- 로그인, 본인 확인 (누구나 아무 이름이나 입력 가능)
- **여러 기기 간 데이터 공유** — 기록은 각 브라우저에만 저장 (데이터베이스 연결은 2차)
- QR 코드 출석, 위치 확인
- 엑셀 내보내기, 통계 그래프
- 교육생 명단 사전 등록

## 7. 성공 기준

- [ ] 휴대폰 화면(폭 약 400px)에서 가로 스크롤 없이 모두 보인다
- [ ] 이름과 번호 입력 후 버튼 한 번으로 출석이 기록된다
- [ ] 09:00 이후 기록은 "지각"으로 표시된다
- [ ] 같은 이름 + 같은 번호를 다시 입력하면 기록되지 않고 안내 문구가 나온다
- [ ] 같은 이름 + 다른 번호는 둘 다 출석된다 (동명이인)
- [ ] 새로고침해도 기록이 남아 있다 (같은 브라우저)
- [ ] 담당자 3명에게 보여 주고 개선 의견을 받는다
