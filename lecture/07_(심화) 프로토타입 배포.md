# 심화 모듈. 프로토타입을 웹에 공개하기 (GitHub + Vercel)

← [[06_PRD로 결과물 만들기 (NotebookLM·생성형 AI)]]

모듈 6에서 Claude로 만든 `index.html` 을 **누구나 접속하는 웹 주소**로 공개합니다. 설치 없이 **웹 브라우저만으로** 진행합니다.

## 흐름과 용어

```
 만들기(index.html) ─▶ 커밋·푸시(GitHub에 기록·업로드) ─▶ 배포(Vercel이 웹 주소로 공개)
```

| 용어 | 한 줄 설명 | 비유 |
|---|---|---|
| **저장소 (Repository)** | 프로젝트 파일과 변경 기록을 담는 곳 | 프로젝트 상자 |
| **커밋 (Commit)** | 변경 내용을 메시지와 함께 기록 | 저장 + 메모 |
| **푸시 (Push)** | 내 컴퓨터의 커밋을 GitHub로 올림 | 택배 발송 |
| **배포 (Deploy)** | 웹 주소로 공개 | 가게 오픈 |

> 💡 웹 브라우저 방식에서는 GitHub 웹사이트에서 파일을 올리는 순간 **커밋과 푸시가 한 번에** 일어납니다. 내 컴퓨터를 거치지 않고 바로 GitHub에 기록되기 때문입니다.

---

## 1. GitHub 계정 만들기 (10분)

1. "업무" Chrome 프로필 창에서 `github.com` → **[Sign up]**
2. **[Continue with Google]** → "업무" 계정 선택 (화면에 이 버튼이 없으면 이메일로 가입)
3. **Username** 정하기: 웹 주소에 들어가므로 영문 소문자로 짧게 (예: `hong-work`)
4. 퍼즐 인증 → (이메일로 가입한 경우) 메일로 온 8자리 코드 입력
5. 설문은 건너뛰고, 요금제는 **Free**
6. ✅ 오른쪽 위에 프로필 아이콘이 보이면 완료

> 시간이 지나면 GitHub이 **2단계 인증(2FA)** 설정을 요구합니다. 인증 앱(Google Authenticator 등)으로 설정하고, **복구 코드는 반드시 따로 저장**하게 안내합니다.

## 2. 저장소 만들기 (5분)

1. 오른쪽 위 **[+]** → **[New repository]**
2. **Repository name**: `attendance-prototype`
3. **Public** 선택 (Vercel 무료 배포가 간단해짐. 단, 누구나 코드를 볼 수 있으니 민감정보 금지)
4. **Add a README file** 체크
5. **[Create repository]**

## 3. 파일 올리기 = 커밋 + 푸시 (5분)

1. 저장소 화면에서 **[Add file]** → **[Upload files]**
2. `index.html` 을 끌어다 놓기
3. 아래 **Commit changes** 칸에 메시지 입력: `출석부 프로토타입 첫 업로드`
4. **[Commit changes]**
5. ✅ 파일 목록에 `index.html` 이 보이고, 옆에 방금 쓴 메시지가 보이면 완료

## 4. Vercel 계정 만들기 (3분)

1. `vercel.com` → **[Sign Up]**
2. 요금제: **Hobby** (무료, 개인용)
3. **[Continue with GitHub]** → GitHub 접근 권한 **[Authorize]**

## 5. 배포하기 (5분)

1. Vercel 대시보드 **[Add New…]** → **[Project]**
2. GitHub 저장소 목록에서 `attendance-prototype` 옆 **[Import]**
   - 목록에 없으면 **GitHub 앱 설치/권한 조정** 링크로 해당 저장소 접근 허용
3. 설정은 기본값 그대로 (Framework Preset: Other) → **[Deploy]**
4. 1분 내외로 축하 화면이 나오면 **[Continue to Dashboard]**
5. ✅ `https://attendance-prototype-xxxx.vercel.app` 같은 주소를 눌러 휴대폰에서도 열어 보기

## 6. 수정 → 자동 재배포 확인 (5분)

1. GitHub 저장소에서 `index.html` 클릭 → 연필(✏️) 아이콘
2. 제목 글자 하나를 바꾸기 (예: `교육생 출석부` → `제12기 출석부`)
3. **[Commit changes]** → 메시지 `제목 수정`
4. 1분 뒤 Vercel 주소를 새로고침 → **바뀐 제목 확인**

> 🎯 이것이 핵심입니다: **GitHub에 커밋하면 Vercel이 알아서 다시 배포**합니다.

## 자주 막히는 곳

| 상황 | 해결 |
|---|---|
| GitHub 인증 메일이 안 옴 | 스팸함/프로모션 탭 확인, 1~2분 뒤 재전송 |
| Vercel에서 저장소가 안 보임 | Import 화면의 GitHub 권한 조정 링크로 저장소 접근 허용 |
| 배포 주소가 404 | 파일 이름이 정확히 `index.html` 인지, 저장소 맨 위에 있는지 확인 |
| 수정했는데 그대로 | 1~2분 대기 후 새로고침, Vercel 대시보드 Deployments에서 진행 상태 확인 |

## ✅ 확인 질문 (인터뷰)

1. 저장소에 `index.html` 과 커밋 메시지가 보이나요?
2. Vercel 주소를 **휴대폰**으로 열어 출석 체크를 해 보셨나요?
3. 제목 수정 후 **자동으로 바뀐 것**을 확인하셨나요?
4. 이 출석부의 기록은 어디에 저장될까요? (정답: 각자의 브라우저 → 공유하려면 데이터베이스가 필요, 다음 회차)
