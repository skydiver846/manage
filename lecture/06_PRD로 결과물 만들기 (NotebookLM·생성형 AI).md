## 한 장의 PRD, 여러 개의 결과물

```
                        ┌─▶ NotebookLM ─▶ 요약 · 오디오 해설 · 마인드맵 · 퀴즈
 📄 PRD.md (옵시디언) ──┼─▶ ChatGPT    ─▶ 보고서 · 안내문 · 발표 개요 · 이미지
                        └─▶ Claude     ─▶ 프로토타입(웹 화면) · 상세 문서
```

| 도구 | 성격 | 이럴 때 |
|---|---|---|
| **NotebookLM** | **내가 넣은 자료 안에서만** 답하는 AI 연구 노트 | 자료를 이해하고 요약·학습할 때 |
| **ChatGPT / Claude** | 일반 지식 + 내 자료를 섞어 **새로 만드는** AI | 문서·화면·이미지 등을 새로 만들 때 |

## 6-1. NotebookLM (약 25분)

### 시작하기
1. "업무" Chrome 프로필 창에서 `notebooklm.google.com` 접속
2. Google 계정으로 로그인 (별도 가입 없음)
3. **[새 노트북 만들기]** (또는 Create new)

### 소스(자료) 넣기
1. **소스 추가** 창에서 **파일 업로드** 선택
2. 옵시디언 보관소 `문서 > AI업무자료 > 01_기획(PRD)` 의 **PRD .md 파일** 선택
3. 함께 참고할 자료가 있으면 추가 (PDF, 텍스트, 웹사이트 주소, YouTube 링크, Google 문서 등)

> 💡 **MD 파일을 바로 올릴 수 있다는 것**이 옵시디언과 NotebookLM 조합의 장점입니다. 형식 변환 없이 옵시디언 노트를 그대로 넣습니다.

### 해 볼 것

| 기능 | 하는 법 | 결과 |
|---|---|---|
| **질문하기** | 가운데 채팅창에 질문 | 답 옆에 **출처 번호**가 붙어 원문 위치 확인 가능 |
| **오디오 개요** | 스튜디오 영역의 오디오 개요 생성 | 두 사람이 PRD를 대화로 설명하는 **팟캐스트형 음성** |
| **마인드맵** | 마인드맵 생성 | 기능 구조를 한눈에 보는 그림 |
| **보고서·학습 가이드** | 보고서 메뉴에서 형식 선택 | 브리핑 문서, 학습 가이드, FAQ 등 |

> 메뉴 이름과 위치는 업데이트로 바뀔 수 있습니다. 오디오 개요는 생성에 몇 분 걸리고, 출력 언어 설정을 한국어로 확인하세요.

### 실습 질문 (NotebookLM 채팅창)

```
이 PRD에서 "범위 밖"으로 정한 것과, 성공 기준을 표로 정리해 줘.
그리고 PRD 안에서 서로 모순되거나 빠진 부분이 있으면 알려 줘.
```

> 강사 포인트: NotebookLM은 **자료에 없는 것을 잘 지어내지 않습니다.** "모순·빠진 부분 찾기"로 **PRD 검토 도구**로 쓰기 좋습니다.

**볼 것 두 가지**
1. **출처 번호** [1], [2] 를 눌러 PRD의 어느 문장을 근거로 했는지 확인 (ChatGPT·Claude와 가장 다른 점)
2. **불일치 찾기**: 모듈 5에서 4번 칸만 "이름 + 번호"로 고쳤다면, 5번 화면 흐름은 아직 "이름 입력"만 있습니다. NotebookLM이 이 불일치를 짚어 주면 옵시디언에서 5·7번 칸을 고치고 **v0.3** 으로 올립니다.

```
 옵시디언에서 PRD 수정 ─▶ NotebookLM에 다시 넣어 검토 ─▶ 불일치 발견 ─▶ 다시 수정
```

> ⚠️ NotebookLM에 올린 파일은 **복사본**입니다. 옵시디언에서 PRD를 고쳐도 NotebookLM 안의 파일은 바뀌지 않으니, 다시 검토하려면 **기존 소스를 지우고 새로 업로드**합니다. 수강생이 가장 헷갈리는 부분입니다.
>
> AI가 불일치를 못 찾으면 "4번과 5번 칸의 입력 항목이 서로 같은지 비교해 줘"처럼 **구체적으로** 다시 묻게 하세요.

> 🧑‍🏫 오디오 개요는 생성에 **수 분**이 걸립니다. 버튼을 먼저 눌러 두고 6-2(ChatGPT)를 진행한 뒤, 완성되면 강의장 스피커로 **30초만** 들려 주세요. 생성이 늦어질 때를 대비해 미리 하나 만들어 두면 좋습니다.

## 6-2. ChatGPT로 만들기 (약 15분)

PRD.md 를 첨부(또는 모듈 3의 프로젝트에 추가)한 뒤:

**① 결재용 보고서**
```
첨부한 PRD를 바탕으로 상급자 결재용 1페이지 보고서를 써 줘.
형식: 제목 / 추진 배경 / 주요 내용 / 기대 효과 / 향후 일정(표).
PRD에 없는 숫자는 만들지 말고 [확인 필요]로 표시해.
```

**② 발표 개요**
```
이 PRD로 10분 발표를 하려고 해. 슬라이드 7장 구성으로
장마다 제목, 핵심 문장 1개, 들어갈 그림 아이디어를 표로 정리해 줘.
```

## 6-3. Claude로 만들기 — 프로토타입 (약 20분)

PRD를 첨부하고 **실제로 눌러 볼 수 있는 화면**을 만들게 합니다.

```
첨부한 PRD를 읽고, 핵심 기능(필수)만 동작하는 프로토타입 웹 화면을 만들어 줘.
- HTML 파일 하나로, 설치 없이 브라우저에서 바로 열리게
- 휴대폰 화면에서도 보기 좋게
- "범위 밖" 기능은 넣지 마
- 처음 열었을 때 예시 데이터 3개를 보여 줘
```

- Claude가 만든 화면은 대화 옆 미리보기 창에서 바로 눌러 볼 수 있습니다. **무료 계정에서도 됩니다.**
- 미리보기 창이 **빈 화면**이면: 미리보기는 `claudeusercontent.com` 이라는 별도 주소에서 그려지는데, 행정망에서 이 주소가 막혔을 수 있습니다. 코드를 복사해 메모장에 `index.html`(UTF-8)로 저장하고 Chrome에서 열면 똑같이 동작합니다.
- 답이 중간에 끊기면 **"계속해 줘"** 라고 입력합니다. 무료 계정에서 사용량 한도에 걸리면 ChatGPT에 같은 지시를 넣어 진행합니다(ChatGPT는 캔버스에서 미리보기).
- 마음에 들지 않는 부분은 대화로 고칩니다: "버튼을 더 크게", "지각 기준을 09:10으로"
- 결과 코드를 복사해 메모장에 붙여넣고 `index.html` 로 저장하면 **내 컴퓨터에서도 열립니다.**

> 예시 결과물: 이 저장소의 `prototype-demo/index.html` 이 [[실습자료/PRD_교육생 출석부 (v0.3 완성본)]] 로 만든 프로토타입입니다. 생성이 늦어지는 수강생을 위해 화면에 띄워 두세요.

> ⭐ **Pro 트랙**: 사용량 여유가 있으니 "버튼 크게", "지각 기준 09:10" 같은 **수정 요청을 여러 번** 해 보며 PRD와 화면을 맞춰 가는 연습을 충분히 합니다.

### PRD의 성공 기준으로 검사하기

미리보기 화면에서 PRD 7번 칸을 그대로 시험해 봅니다.

| 성공 기준 | 해 보기 | 결과 |
|---|---|---|
| 이름 + 번호로 출석이 기록된다 | `김소방`, `01` 입력 → 출석 | ☐ |
| 09:00 이후는 지각으로 표시된다 | 명단의 시각과 표시 확인 | ☐ |
| 같은 이름 + 같은 번호는 막힌다 | `김소방`, `01` 다시 입력 | ☐ |
| **같은 이름 + 다른 번호는 둘 다 출석된다** | `김소방`, `02` 입력 | ☐ |

> 🧑‍🏫 핵심 멘트: "모듈 3에서 AI가 찾은 구멍, 모듈 5에서 우리가 고친 규칙이 지금 **화면에서 그대로 동작**합니다. PRD에 적었기 때문입니다."
>
> 화면에서 바꾼 규칙(예: 지각 기준 09:10)은 **PRD에도 반영**합니다. 기준 문서는 언제나 PRD입니다.
>
> 이 화면의 기록은 **각자의 브라우저에만** 저장됩니다. "다른 휴대폰에서도 같은 명단을 보려면?"이라는 질문이 나오면 심화 회차로 연결하세요.

## 6-4. 결과물 정리 — 다시 옵시디언으로

```
📁 AI업무자료
 ├─ 📁 01_기획(PRD)      ← PRD_교육생 출석부.md (원본)
 ├─ 📁 03_AI결과물
 │   ├─ 결재 보고서.md      (ChatGPT)
 │   ├─ 발표 개요.md        (ChatGPT)
 │   ├─ PRD 검토 결과.md    (NotebookLM)
 │   └─ 프로토타입/index.html (Claude)
```

**순환 구조**: 결과를 보고 → PRD 수정 → 다시 생성. PRD가 좋아질수록 모든 결과물이 함께 좋아집니다.

## 자주 막히는 곳

| 상황 | 해결 |
|---|---|
| NotebookLM에서 MD 파일이 안 보임 | 파일 선택 창 오른쪽 아래 형식이 "모든 파일"인지 확인 |
| 오디오 개요가 영어로 나옴 | 출력 언어 설정(설정 메뉴)을 한국어로 변경 후 다시 생성 |
| 프로토타입 HTML이 메모장 저장 후 안 열림 | 저장 시 "파일 형식: 모든 파일", 인코딩 **UTF-8** 선택, 확장자 `.html` 확인 |
| 결과물마다 내용이 다름 | 정상입니다. 기준은 **PRD**. 결과물은 PRD와 대조해 검토 |

## ✅ 확인 질문 (인터뷰)

1. NotebookLM에서 **출처 번호가 붙은 답**을 받아 보셨나요?
2. 오디오 개요를 들어 보셨나요? PRD를 처음 듣는 사람도 이해할 만했나요?
3. Claude가 만든 프로토타입에서 **버튼을 눌러 동작**을 확인하셨나요?
4. 결과물을 보고 **PRD에서 고칠 점**을 하나 찾으셨나요?
