# 생성형 AI 업무 활용 입문 — 강의 개요

> 대상: 컴퓨터는 쓰지만 AI 도구·GitHub 계정이 **하나도 없는** 처음 시작하는 분
> 환경: Windows + Chrome 브라우저
> 진행 방식: 강사가 단계마다 **확인 질문(인터뷰)** 을 던지고, 모두 "완료"하면 다음 단계로

---

## 이 과정의 방향

- **AI를 처음 쓰는 분**이 흥미를 잃지 않게, 모든 모듈은 **쉽고 짧은 실습 하나**로 시작해 결과물이 눈에 보이게 끝납니다. 각 모듈 맨 위에 "🎯 이 모듈에서 만들 것"을 적어 두었습니다.
- 과정 전체를 꿰는 줄기는 **웹페이지를 만들고 배포해 보는 것**입니다.

```
03 말로 만든 계산기 → 첫 웹 주소 보기 ─▶ 07 내 PRD로 내 화면 시안 ─▶ 09 화면 구조 ─▶ 10 Netlify 배포 ─▶ 12 내 업무 화면 배포
(1일차 1교시)                              (1일차 5교시)    (2일차 7교시 · 맛보기와 배포)       (2일차 8~9교시)
```

- 그리고 **꾸준히 하면 업무 자동화까지 갈 수 있다**는 방향을 "업무 자동화 사다리"로 보여 줍니다. 각 모듈 끝의 🪜 줄이 지금 몇 번째 칸인지 알려 주고, 과정 뒤에는 [[과제 안내]]의 4주 계획으로 한 칸씩 이어 갑니다.

```
① 잘 시키기 → ② 자료 맡기기 → ③ 방법 맡기기 → ④ 클릭 맡기기 → ⑤ 내 도구 만들기 → ⑥ 저절로 돌아가게
  (03)          (03·05)          (06)            (08)            (07·09·10·12)       (과정 뒤 스스로)
```

## 강의 목표

수업이 끝나면 교육생은 다음을 **혼자서** 할 수 있습니다.

1. 업무용 Google 계정을 만들고 Chrome "업무" 프로필 창에서 쓴다
2. ChatGPT와 Claude에 가입하고, 좋은 프롬프트로 원하는 답을 얻는다
3. AI에 **파일을 건네고**, **프로젝트(폴더)** 로 자료를 묶어 반복 작업을 줄인다
4. AI의 인터뷰를 받아 MD 파일로 **PRD(기획서)** 를 쓴다
5. 자주 하는 일의 방법을 MD 파일(**SKILL.md**)로 적어 **스킬**로 AI에게 맡긴다
6. 그 PRD를 Gemini Notebook·Claude에 넣어 **요약, 발표자료, 오디오 해설, 프로토타입**을 만든다

## 실습 주제: AI 시대, 여행 계획이 달라졌다 — 우리 집 여행 담당의 이틀

업무 분야는 사람마다 달라 모두가 공감하는 업무 예시를 찾기 어렵습니다. 그래서 공통 예시는 누구나 한 번쯤 겪는 **가족 여행 준비**로 하고, 배운 흐름을 마지막에 **내 업무로 옮깁니다.** 흐름(시키기 → 자료 맡기기 → 방법 맡기기 → 클릭 맡기기 → 내 도구 만들기)은 주제가 바뀌어도 똑같습니다.

- **설정**: 경주 2박 3일(가을 주말), 광주에서 자가용. 가족 4명 = 나 · 배우자 · 아이(초등 3학년) · 할머니(75세, 무릎이 불편해 오래 걷기·계단이 어려움)
- **여는 이야기**: 지난주 직원들에게 공유한 **여행길 도우미** 사이트를 QR로 띄워 "한 번씩 써 보셨나요?" → "코딩 없이 AI와 대화로 만들었습니다. 이틀 뒤 여러분도 휴대폰으로 여는 내 화면을 만듭니다."
- "아빠·엄마" 대신 **여행 담당**이라고 부릅니다. 자녀가 없거나 혼자 사는 분도 자기 이야기로 받아들이게 하기 위해서입니다.

| 단계 | 지금 (손으로) | 이 강의에서 (AI와 함께) | 모듈 | 💼 업무에서는 |
|---|---|---|---|---|
| 일정 짜기 | 블로그 탭 20개, 단톡방 "어디 갈래?" | 5요소 프롬프트로 가족 조건이 반영된 일정 | 03 | 안내문·공문 초안 |
| 자료 정리 | 후기를 하나하나 읽고 메모 | 관광지 자료·후기를 건네 장소별 표로 (모르는 요금·시간은 [확인 필요]) | 03 · 07 | 규정·공문 요약 |
| 준비물 화면 기획 | 단톡방에 생각나는 대로 | PRD 작성, AI가 구멍(**누구 것인지 구분 없음**) 찾기 | 03 · 05 | 업무 도구 기획 |
| 여행 일정표 | 여행마다 새로 | 스킬(`trip-plan`)로 양식 고정, "제주 3일" 한 마디로 | 06 · 07 | 주간보고·결과보고 양식 |
| 가족 공유 자료 | 직접 정리해 단톡방에 | Gemini Notebook 라디오 해설·슬라이드, Claude로 안내 한 장 | 07 | 발표자료·결재 보고서 |
| 축제·날씨 확인 | 매번 검색 | **코딩 없이** AI 브라우저(Aside)가 찾아 정리, 루틴으로 매일 아침 날씨 확인. 예약·결제는 사람이 | 08 | 공지 확인·자료 내려받기 |
| 준비물 체크 | 출발 전날 단톡방 다시 읽기 | 가족별 챙김률을 계산하는 화면(50% 미만 "서둘러요") | 07 · 09 | 행사·교육 준비 체크리스트 |
| 가족에게 공유 | 캡처해서 보내기 | 화면을 웹 주소로 공개(배포)해 단톡방에 링크. 각자 체크하면 흩어지는 것 확인, **공용 장부는 개념만** | 10 | 부서 안내 페이지, 회신 취합의 어려움 |
| 내 도구 | 없음 | 05에서 쓴 **내 PRD**(업무든 일상이든, 또는 공공데이터 CSV)로 Claude Code가 화면을 만들고 배포 | 12 | 내 업무 화면 |

> 🧑‍🏫 목적에서 벗어났다는 인상을 주지 않도록 각 모듈 끝에 "💼 업무에서는?" 한 줄을 넣었습니다. 10교시 적용 계획에서는 위 표의 오른쪽 칸(여행 담당 → 업무 담당 다리)을 띄워 두고 "다음 주에 쓸 한 가지"를 정하게 하세요. 여행길 도우미의 날씨·주차 카드가 시연 중에 안 뜨면 "AI가 만든 것도 확인이 필요하다"(12의 4단계)로 연결합니다. APK 설치는 권하지 않고 언급만 합니다.

### 기수별 피드백 수집 (운영 개선용)

- 강의자료를 고치면 `npm run build` 로 다시 만들어 저장소에 다시 올립니다.

## 자료 배포: 데스크톱이므로 QR보다 링크

QR은 휴대폰 카메라로 찍는 것이라 **데스크톱 PC로는 자료를 받을 수 없습니다.**

| 용도 | 방법 |
|---|---|
| 강의자료·실습 파일 배포 | **짧은 주소를 화면에 띄워 직접 입력**하거나, PC 메신저·메일로 **링크 공유**. 인터넷이 불안하면 실습 파일을 강의장 PC 바탕화면에 미리 복사 |
| 배포한 준비물 화면에서 체크해 보기 (모듈 10·12) | **QR 사용**: 교육생 본인 휴대폰(LTE)으로 열어 보기 |

## 계정: Claude Team (기관 유료 계정)

이 과정은 기관이 준비한 **Claude Team** 계정으로 진행합니다. 교육생 모두가 같은 유료 화면을 쓰므로 무료/유료 트랙을 나누지 않고, **스킬 등록(06)과 Claude Code(12)까지 전원이 직접 실습**합니다.

| 구분 | 내용 |
|---|---|
| 요금 | 일반 좌석(Standard) 1인 월 $25 (월 결제). 20명 한 달 약 $500 + 부가세. 연 결제는 1년 약정이라 단기 교육에 맞지 않음 |
| 포함 기능 | 스킬, 프로젝트(팀 공유 가능), 미리보기, **Claude Code** (모든 좌석 포함, 2026-10 요금 페이지 확인) |
| 데이터 | 기업용 기본 설정으로 대화 내용을 모델 학습에 쓰지 않음 |
| 무료·Pro와 비교 | 기능별 비교표는 [[02_ChatGPT와 Claude 가입]] 의 "Claude 요금제 비교" |
| 강사 | Team 관리자(Owner). 강사 개인 Pro 계정에 Team이 함께 붙으므로, **시연은 Team 쪽 화면**, 강사용 열람 페이지는 개인 쪽에서 엶 |

| 시점 | 누가 | 할 일 |

## 교육생 사전 준비물

**사전 과제 (수업 전, 각자)**

```
□ 구글 계정 만들기 (업무용 1개 이상) — 모듈 01
□ ChatGPT 가입, 업무 이메일 제출 → Claude Team 초대 메일 수락 — 모듈 02
□ GitHub 가입 — 모듈 10의 1단계
```

**준비물**

```
□ 강의장 데스크톱 PC (Windows + Chrome) — 강사가 사전 점검 (Aside 설치 가능 여부 포함)
□ 본인 명의 휴대폰 (문자 인증용, 반드시 본인 번호 / 모듈 10·12에서 직접 만든 화면 확인용)
□ 업무 계정 이름 아이디어 (예: hong.gildong.work)
□ 비밀번호를 적어 둘 수첩 또는 비밀번호 관리 앱
□ 내 업무 중 "AI로 도움받고 싶은 일" 한 가지 (PRD 실습 주제)
```
