# 생성형 AI 업무 활용 입문 — 강의 개요

> 대상: 컴퓨터는 쓰지만 AI 도구·옵시디언·GitHub 계정이 **하나도 없는** 처음 시작하는 분
> 환경: Windows + Chrome 브라우저
> 진행 방식: 강사가 단계마다 **확인 질문(인터뷰)** 을 던지고, 모두 "완료"하면 다음 단계로

---

## 강의 목표

수업이 끝나면 수강생은 다음을 **혼자서** 할 수 있습니다.

1. 용도별 Google 계정을 만들고 Chrome에서 바꿔 가며 쓴다
2. ChatGPT와 Claude에 가입하고, 좋은 프롬프트로 원하는 답을 얻는다
3. AI에 **파일을 건네고**, **프로젝트(폴더)** 로 자료를 묶어 반복 작업을 줄인다
4. 옵시디언에서 MD 파일로 **PRD(기획서)** 를 쓴다
5. 그 PRD를 NotebookLM·ChatGPT·Claude에 넣어 **요약, 발표자료, 오디오 해설, 프로토타입**을 만든다

## 강의장 환경: 행정망 데스크톱

이번 강의는 **행정망에 연결된 강의장 데스크톱 PC**에서 진행합니다.

| 항목 | 리허설 결과 | 수업 전 할 일 |
|---|---|---|
| GitHub · Vercel 배포 (모듈 08) | ✅ 행정망 리허설에서 배포까지 확인 | 없음 |
| Firebase (모듈 09) | ❓ 아직 확인 전 | **접속 점검 페이지**로 확인 → A안(수강생 실습) 또는 B안(강사 시연) 결정 |
| ChatGPT · Claude · NotebookLM (모듈 02~06) | 점검 필요 | 접속 점검 페이지로 확인. 막혀 있으면 전산 담당자에게 강의 시간 동안 접속 허용 요청 |
| 옵시디언 설치 (모듈 04) | 점검 필요 | 기관 PC는 프로그램 설치가 막혀 있을 수 있음. 막히면 전산 담당자에게 사전 설치 요청, 안 되면 메모장으로 진행 |

**접속 점검 페이지**: 저장소 `prototype-demo/network-check.html`
- 강의장 PC의 Chrome에서 열면 강의에 쓰는 사이트(Google, ChatGPT, Claude, NotebookLM, 옵시디언, GitHub, Vercel, Firebase)가 열리는지 자동으로 보여 줍니다.
- 2단계에서 Firebase 설정값을 붙여넣으면 **공용 장부에 실제로 접속되는지**까지 시험하고, 모듈 09를 A안으로 할지 B안으로 할지 판정해 줍니다.
- 열기 쉬운 방법: 리허설 때 쓴 GitHub 저장소에 이 파일을 올려 두면 `내주소.vercel.app/network-check.html` 로 열 수 있습니다(행정망에서 Vercel이 열리는 것을 확인했으므로).

## 자료 배포: 데스크톱이므로 QR보다 링크

QR은 휴대폰 카메라로 찍는 것이라 **데스크톱 PC로는 자료를 받을 수 없습니다.**

| 용도 | 방법 |
|---|---|
| 강의자료·실습 파일 배포 | **짧은 주소를 화면에 띄워 직접 입력**하거나, PC 메신저·메일로 **링크 공유**. 인터넷이 불안하면 실습 파일을 강의장 PC 바탕화면에 미리 복사 |
| 배포한 출석부 확인 (모듈 08) | **QR 사용**: 수강생 본인 휴대폰(LTE)으로 열어 보기 |

## 비용: 전 과정 무료 (카드 등록 불필요)

| 서비스 | 무료 요금제 | 수업 중 주의할 한도 |
|---|---|---|
| ChatGPT · Claude | 무료 | 실습이 몰리면 사용량 한도에 걸릴 수 있음. 한쪽이 막히면 다른 쪽으로 진행 |
| NotebookLM | 무료 | 오디오 개요 생성 횟수에 하루 한도 |
| GitHub | Free | 공개·비공개 저장소 모두 무료 |
| Vercel | Hobby | 개인·비상업 용도 조건. 실습은 문제없음, 기관 정식 서비스는 별도 검토 |
| Firebase | Spark | Firestore 하루 읽기 약 5만·쓰기 약 2만 건. **Blaze 업그레이드만 누르지 않으면** 요금 없음 |

> 🧑‍🏫 요금제 이름과 한도는 서비스 정책에 따라 바뀔 수 있습니다. 강의 직전에 한 번 확인하세요.

## 수강생 사전 준비물

```
□ 강의장 데스크톱 PC (Windows + Chrome) — 강사가 사전 점검
□ 본인 명의 휴대폰 (문자 인증용, 반드시 본인 번호 / 모듈 08·09에서 출석부 확인용)
□ 계정 이름 아이디어 (예: hong.gildong → hong.gildong.work / hong.gildong.lab)
□ 비밀번호를 적어 둘 수첩 또는 비밀번호 관리 앱
□ 내 업무 중 "AI로 도움받고 싶은 일" 한 가지 (PRD 실습 주제)
```

## 강사 진행 원칙

- **한 번에 한 단계.** 화면을 띄우고 함께 누른 뒤 "확인 질문"으로 전원 완료를 확인합니다.
- **막히면 표로.** 각 모듈 끝의 "자주 막히는 곳" 표를 먼저 확인합니다.
- **개인정보 주의.** 실습에는 실제 개인정보·내부 문서 대신 예시 자료를 씁니다.
