## 3-1. 프롬프트: 좋은 지시의 5요소 (20분)

### 공식: **역할 · 목표 · 맥락 · 형식 · 조건**

| 요소 | 질문 | 예시 |
|---|---|---|
| **역할** | 누구처럼 답할까? | "너는 소방학교 교육 담당자야" |
| **목표** | 무엇을 원하나? | "신임 교육생 오리엔테이션 안내문을 써 줘" |
| **맥락** | 배경은? | "교육생 40명, 3주 과정, 첫날 09:00 집합" |
| **형식** | 어떤 모양으로? | "제목 + 5개 항목 글머리표, A4 반 장" |
| **조건** | 지킬 것은? | "존댓말, 준비물은 표로, 과장 표현 금지" |

### 실습: 나쁜 프롬프트 vs 좋은 프롬프트

**나쁜 예**
```
오리엔테이션 안내문 써줘
```

**좋은 예**
```
[역할] 너는 소방학교 교육운영 담당자야.
[목표] 신임소방관 교육생에게 보낼 첫날 오리엔테이션 안내문을 써 줘.
[맥락] 교육생 40명, 3주 과정, 첫날 09:00 본관 강당 집합, 개인 체력복 지참.
[형식] 제목 1줄, 인사말 2줄, 핵심 안내 5개 항목(글머리표), 준비물은 표로.
[조건] 정중한 존댓말, A4 반 장 이내, 확인되지 않은 내용은 [확인 필요]로 표시.
```

> 💡 둘을 **Claude에서 새 채팅 2개**로 나눠 넣고 나란히 비교합니다. 대부분 "좋은 예"가 바로 쓸 수 있는 결과를 냅니다.

> 🧑‍🏫 강사 포인트
> - "나쁜 예"에서 AI가 날짜·장소를 **지어낸** 부분을 짚어 주세요 (모듈 2의 "AI는 틀릴 수 있다"와 연결).
> - 수강생에게 "어느 줄이 가장 효과가 컸나요?"라고 물으면 대부분 **조건**을 꼽습니다. `확인되지 않은 내용은 [확인 필요]로 표시해` 한 줄이 지어내기를 막아 준다고 정리하세요.
> - 다섯 요소를 다 쓰기 어려우면 **맥락**과 **조건** 두 개만이라도 챙기게 합니다.

### 첨삭 예시: 공식은 지켰는데 맥락이 빈 프롬프트

**수강생 초안**
```
[역할] 너는 소방공무원이야.
[목표] 장비 점검 결과 보고 메일 써 줘.
[맥락] 이번 달 장비 점검했음.
[형식] 메일로.
[조건] 존댓말.
```

강사는 직접 고쳐 주지 말고 아래 **질문을 던져** 수강생이 스스로 채우게 합니다.

| 요소 | 강사 질문 | 고친 내용 |
|---|---|---|
| 역할 | "누가 누구에게 보내나요?" | ○○119안전센터 장비 담당자 → **센터장에게** 보고 |
| 목표 | "보고만? 요청도 있나요?" | 결과 보고 + **교체 예산 요청** |
| **맥락** | "숫자와 날짜는요?" | 10월 1~2일, 공기호흡기 12대 점검, 정상 10대, **2대 압력 게이지 불량** |
| 형식 | "메일의 어떤 부분이 필요한가요?" | 제목 1줄, 본문 3문단, 점검 결과는 표 |
| 조건 | "지어내면 안 되는 것은요?" | 존댓말, **예산 금액은 [확인 필요]로** |

**고친 프롬프트**
```
[역할] 너는 ○○119안전센터 장비 담당자야. 센터장님께 보고 메일을 쓰는 상황이야.
[목표] 이번 달 장비 점검 결과를 보고하고, 불량 장비 교체 예산을 요청하는 메일을 써 줘.
[맥락] 10월 1~2일 공기호흡기 12대 점검. 정상 10대, 2대는 압력 게이지 불량으로 사용 중지함.
[형식] 메일 제목 1줄, 본문 3문단(결과 요약 / 불량 내용 / 요청 사항), 점검 결과는 표로.
[조건] 정중한 존댓말. 예산 금액이나 교체 일정처럼 내가 주지 않은 정보는 [확인 필요]로 표시해.
```

> 핵심 멘트: "AI는 우리 센터 장비가 몇 대인지 절대 알 수 없습니다. **내가 아는 사실은 내가 건네야** 합니다."

### 대화로 다듬기 (되묻기 기술)

한 번에 완벽하게 쓰려고 하지 않아도 됩니다. 이어서 지시합니다.
- "3번 항목을 더 짧게"
- "표를 날짜순으로 정렬해 줘"
- "문자 메시지용으로 200자 이내 버전도 만들어 줘"
- **"내가 빠뜨린 정보가 있으면 먼저 질문해 줘"** ← 가장 유용한 한 문장

## 3-2. 파일 건네기 (15분)

### 방법
- 입력창의 **[+]** 버튼(또는 클립 아이콘) → 파일 선택
- 또는 파일을 입력창으로 **끌어다 놓기(드래그 앤 드롭)**

### 어떤 파일이 잘 되나?

| 잘 됨 | 주의 |
|---|---|
| PDF, Word, 텍스트(.txt), **Markdown(.md)**, 엑셀/CSV, 이미지(사진·캡처) | 스캔한 흐린 PDF, 암호 걸린 파일, 아주 큰 파일 |

> 💡 **MD 파일이 특히 좋은 이유**: 제목·목록·표 구조가 그대로 전달되어 AI가 문서 구조를 정확히 이해합니다. 그래서 모듈 4에서 옵시디언으로 MD 파일을 만듭니다.

### 실습 프롬프트 (파일 첨부 후)

```
첨부한 문서를 읽고
1) 핵심 내용 3줄 요약
2) 실제로 해야 할 일(To-do) 목록
3) 문서에서 모호하거나 빠진 부분
을 표로 정리해 줘. 문서에 없는 내용은 지어내지 마.
```

> 연습 파일: [[실습자료/PRD_교육생 출석부]] 를 첨부해 보세요.
> 강의 전에 이 파일을 **Google Drive 공유 링크**로 준비해 두고, 수강생은 **다운로드 폴더**에 받습니다. `.md` 파일을 더블클릭하면 앱 선택 창이 뜰 수 있으니 열지 말고 바로 AI에 올리게 하세요.

- 파일을 올리면 입력창 위에 **파일 이름 카드**가 생깁니다. 카드만 보내지 말고 **파일 + 지시**를 함께 보냅니다.

### 🔍 AI가 찾아 주는 구멍: "동명이인"

요약표의 3번 **"빠진 부분"** 에서 AI는 보통 이 PRD의 구멍을 찾아냅니다. 대표적인 것이 **동명이인 처리**입니다. PRD에는 "같은 이름으로 두 번 출석하면 막는다"는 규칙이 있어서, 이름이 같은 교육생이 두 명이면 두 번째 사람은 출석할 수 없습니다.

> 🧑‍🏫 강사 포인트: AI는 글을 **써 주는** 도구이면서 **검토해 주는** 도구입니다. 화이트보드에 **"빠진 부분: 동명이인"** 이라고 적어 두고, 모듈 5에서 PRD를 고칠 때 다시 꺼내세요.

## 3-3. 폴더처럼 쓰기: 프로젝트 기능 (25분)

매번 같은 자료를 올리고 같은 설명을 반복하는 일을 없애는 기능입니다.

```
📁 프로젝트: "교육운영 업무"
 ├─ 📄 지침(Instructions): "너는 소방학교 교육운영 담당자 보조야. 항상 존댓말, 표 활용…"
 ├─ 📎 파일: 교육 일정표.md, 운영 규정.pdf, PRD_교육생 출석부.md
 └─ 💬 대화 1, 대화 2, 대화 3 …  ← 모두 위 지침과 파일을 자동으로 참고
```

### ChatGPT에서 프로젝트 만들기
1. 왼쪽 사이드바 **[프로젝트]** 옆 **[+]** (또는 [새 프로젝트])
2. 이름 입력 (예: `교육운영 업무`)
3. 프로젝트 화면에서 **파일 추가**, **지침(Instructions)** 입력
4. 프로젝트 안에서 새 대화를 시작

### Claude에서 프로젝트 만들기
1. 왼쪽 사이드바 **[Projects]** → **[+ 새 프로젝트]**
2. 이름과 설명 입력 → [만들기]
3. 오른쪽 **프로젝트 지식(Project knowledge)** 에 파일 추가
4. **지침(Instructions)** 설정 → 프로젝트 안에서 대화 시작

> 메뉴 이름과 위치는 서비스 업데이트에 따라 조금씩 바뀔 수 있습니다. 무료 요금제에서는 프로젝트 수나 파일 수에 제한이 있을 수 있습니다.

### 효과 확인: 짧게 물어보기

프로젝트 안에서 파일도, 역할도 없이 **한 줄만** 입력합니다.
```
교육생 출석부 기능을 정리해 줘
```
PRD 내용을 근거로 **표**로 정리하고, 끝에 **"다음에 할 일"** 까지 붙어 나오면 지침과 파일이 제대로 동작하는 것입니다.

> 🧑‍🏫 숙제로 연결: "내 업무 중 프로젝트로 만들어 두면 좋을 것은?" (예: 교육 일정 관리 → 일정표를 파일로 넣고, 지침에 "날짜는 표로, 겹치는 일정은 경고")

### 지침(Instructions) 예시 — 복사해서 사용

```
너는 소방학교 교육운영 담당자를 돕는 보조자야.
- 항상 정중한 존댓말로 답한다.
- 프로젝트에 올린 파일 내용을 우선 근거로 삼고, 파일에 없는 내용은 [확인 필요]로 표시한다.
- 일정·인원·준비물은 표로 정리한다.
- 답 끝에 "다음에 할 일" 1~3개를 제안한다.
```

### 내 컴퓨터 폴더도 정리하기

AI에 건넬 자료가 흩어져 있으면 매번 찾느라 시간이 듭니다. 아래 구조를 추천합니다. (모듈 4의 옵시디언 보관소가 이 폴더가 됩니다)

```
📁 AI업무자료
 ├─ 📁 01_기획(PRD)
 ├─ 📁 02_참고자료
 ├─ 📁 03_AI결과물
 └─ 📁 99_프롬프트
```

## 자주 막히는 곳

| 상황 | 해결 |
|---|---|
| 파일을 올렸는데 "읽을 수 없다"고 함 | 스캔 PDF면 텍스트가 없는 것. 원본 파일이나 MD/텍스트로 다시 |
| 답이 너무 길거나 짧음 | 형식 요소에 분량을 숫자로 지정 ("5줄", "300자") |
| 사실과 다른 내용이 섞임 | "문서에 없는 내용은 지어내지 마" 조건 추가, 결과는 반드시 원문 대조 |
| 프로젝트 메뉴가 안 보임 | 왼쪽 사이드바가 접혀 있는지 확인(왼쪽 위 아이콘) |

## ✅ 확인 질문 (인터뷰)

1. 5요소 공식으로 **내 업무 프롬프트** 하나를 써서 실행해 보셨나요?
2. 파일을 첨부해 **요약표**를 받아 보셨나요?
3. ChatGPT나 Claude 중 한 곳에 **프로젝트 1개**를 만들고 지침을 넣으셨나요?
