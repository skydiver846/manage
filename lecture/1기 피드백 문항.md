# 1기 피드백 문항 (네이버 폼에 붙여넣기용)

> 🧑‍🏫 강사용 자료입니다. 출구 카드는 하루에 1개(1일차·2일차, 같은 폼을 복사해 선택지만 바꿈), 과정 평가는 12교시에 1개를 만듭니다. 모두 **익명**으로 설정하고, 폼 주소는 QR로 띄워 휴대폰으로 받습니다. 결과는 엑셀로 내려받아 2기 커리큘럼을 정할 때 씁니다.

---

## A. 출구 카드 (하루가 끝날 때, 2분)

**폼 제목:** `생성형 AI 업무 활용 입문 1기 — ○일차 출구 카드`
**폼 설명:** `오늘 수업을 2분 안에 돌아봅니다. 익명이며, 다음 날 수업과 2기 과정을 고치는 데만 씁니다.`

**1. 오늘 가장 쓸모 있었던 것은? (객관식, 1개, 필수)**
**2. 오늘 가장 어려웠던 것은? (객관식, 1개, 필수)** — 1번과 같은 선택지 + `어려운 것 없었음`

| 일차 | 선택지 (1·2번 공통) |
|---|---|
| 1일차 | 몸풀기 HTML(계산기·게임) / 프롬프트 5요소 / 파일 건네기(자유의견 요약) / 프로젝트 / 옵시디언·MD 파일 / PRD 작성 / 스킬 만들기 / 내 업무 스킬 / Gemini 슬라이드·인포그래픽 / Claude 결재 보고서 / 기타(직접 입력) |
| 2일차 | AI 브라우저(Aside) / HTML·CSS·JS 화면 구조 / GitHub·Vercel 배포 / Claude Code로 내 화면 만들기 / 공공데이터 화면 / 결과 공유 / 기타(직접 입력) |

**3. 오늘 시간이 어땠나요? (객관식, 1개, 필수)**
- 전체적으로 시간이 모자랐다
- 적당했다
- 시간이 남았다

**4. 시간이 특히 모자랐던 교시는? (체크박스, 여러 개, 선택)**

| 일차 | 선택지 |
|---|---|
| 1일차 | 1교시 프롬프트 / 2교시 파일·프로젝트 / 3교시 옵시디언 / 4교시 PRD / 5교시 스킬 / 6교시 보고 자료 / 없음 |
| 2일차 | 7교시 AI 브라우저 / 8교시 화면 구조 / 9교시 배포 / 10~11교시 내 화면 만들기 / 12교시 공유 / 없음 |

**5. 한 줄 의견 (단답형, 선택)**
`내일 수업에 바라는 점이나 막혔던 곳을 자유롭게 적어 주세요.`

## B. 과정 평가 (12교시, 약 10분)

**폼 제목:** `생성형 AI 업무 활용 입문 1기 — 과정 평가`
**폼 설명:** `1기는 2기 과정을 만들기 위한 시범 과정입니다. 솔직한 의견이 가장 큰 도움이 됩니다. 익명이며 약 7분 걸립니다.`

### 1. 나에 대해 (선택)

**1-1. 교육 전 생성형 AI(ChatGPT·Claude 등) 사용 경험은? (객관식)**
- 써 본 적 없음
- 몇 번 써 봄
- 가끔 업무에 씀 (월 몇 회)
- 자주 업무에 씀 (주 1회 이상)

**1-2. 담당 업무 분야는? (객관식)**
- 교육·교수 업무
- 행정·지원 업무
- 기타

### 2. 과정 전체 (필수, 1~5점: 1 매우 아니다 ~ 5 매우 그렇다)

| 번호 | 문항 |
|---|---|
| 2-1 | 과정 전반에 만족한다 |
| 2-2 | 배운 내용이 내 업무에 도움이 된다 |
| 2-3 | 과정이 끝난 뒤에도 혼자 계속 쓸 수 있다 |
| 2-4 | 강의 자료(강의 사이트, 실습 파일)가 따라 하기 쉬웠다 |
| 2-5 | 동료에게 이 과정을 추천하겠다 |

**2-6. 전체 난이도는? (객관식, 필수)**
- 너무 쉬웠다 / 조금 쉬웠다 / 적당했다 / 조금 어려웠다 / 너무 어려웠다

**2-7. 총 시간(12시간)은? (객관식, 필수)**
- 짧았다 / 적당했다 / 길었다

**2-8. 2일 연속(하루 6시간)으로 진행한 방식은? (객관식, 필수)**
- 좋았다 (집중해서 배울 수 있었다)
- 보통이다
- 나눠서(예: 4시간씩 3회) 하는 편이 낫겠다

### 3. 교시별 평가 (필수)

> 네이버 폼의 **표형(그리드) 객관식**을 쓸 수 있으면 행에 교시, 열에 점수를 둡니다. 없으면 교시별로 객관식 문항을 나눠 만듭니다.

**3-1. 교시별로 업무에 얼마나 도움이 되었나요? (1~5점)**
**3-2. 교시별 난이도는? (쉬움 / 적당 / 어려움)**

| 행 (교시) |
|---|
| 1교시 생성형 AI 첫 경험과 프롬프트 |
| 2교시 파일 건네기와 프로젝트 |
| 3교시 옵시디언과 MD 파일 |
| 4교시 업무 기획서(PRD) 작성 |
| 5교시 스킬로 업무 방법 맡기기 |
| 6교시 PRD로 보고 자료 만들기 |
| 7교시 코딩 없이 업무 자동화 (AI 브라우저) |
| 8교시 웹 화면의 구조 (HTML·CSS·JS) |
| 9교시 내 화면을 웹에 공개 (GitHub·Vercel) |
| 10~11교시 AI 에이전트로 내 업무 화면 만들기 (Claude Code) |
| 12교시 결과 공유와 업무 적용 계획 |

### 4. 앞으로 (필수)

**4-1. 앞으로 업무에 계속 쓸 것 같은 것은? (체크박스, 여러 개)**
- 프롬프트 5요소
- 파일 건네기 (요약·검토)
- 프로젝트 (자료·지침 묶어 두기)
- 옵시디언·MD 파일
- PRD (기획서)
- 스킬 (업무 방법 맡기기)
- Gemini 슬라이드·인포그래픽
- AI 브라우저 (Aside)
- 웹 배포 (GitHub·Vercel)
- Claude Code (내 화면 만들기)
- 없음

**4-2. 2기에서 빼거나 줄여도 될 것은? (체크박스, 여러 개, 선택)** — 3번 표의 교시 11개 + `없음`

**4-3. 2기에서 더 배우고 싶은 것은? (체크박스, 여러 개)**
- 공문·보고서 작성 심화 (우리 기관 양식)
- 엑셀·데이터 정리와 분석
- 회의록·녹음 정리
- 홍보물·카드뉴스 만들기 (캔바 등)
- 짧은 영상(숏폼) 만들기
- 내 업무 화면 더 발전시키기 (Claude Code)
- 업무 자동화 더 하기 (AI 브라우저·루틴)
- AI 사용 보안·개인정보 지침
- 기타(직접 입력)

### 5. 자유 의견 (선택)

**5-1. 가장 좋았던 점 (단답형)**
**5-2. 고쳤으면 하는 점 (단답형)** — `시간 배분, 자료, 실습 환경(행정망·설치) 등 무엇이든`
**5-3. 강사에게 하고 싶은 말 (단답형)**

## C. 결과 정리 기준 (2기 설계용)

| 지표 | 계산 | 2기 판단 |
|---|---|---|
| 교시별 유용도 평균 (3-1) | 교시마다 평균 | 4.0 이상: 유지·확대 후보 / 3.0 미만: 축소·선택 과정 후보 |
| 교시별 "어려움" 비율 (3-2) | 교시마다 비율 | 40% 이상이면 시간을 늘리거나 사전 과제로 일부를 뺌 |
| 계속 쓸 것 (4-1) | 선택 비율 | 상위 3개는 2기 핵심으로 |
| 빼도 될 것 (4-2) | 선택 비율 | 30% 이상이면 2기에서 축소·선택 과정 후보 |
| 더 배우고 싶은 것 (4-3) | 선택 비율 | 상위 2~3개를 2기 신규 교시 후보로 |
| 출구 카드 3·4번 | 일차별 집계 | 시간이 모자란 교시는 2기에서 시간 조정 |

> 🧑‍🏫 이 결과표 정리도 수업에서 배운 방법 그대로 할 수 있습니다. 네이버 폼 결과 엑셀을 Claude 프로젝트에 넣고 "교시별 유용도 평균과 어려움 비율을 표로, 2기 커리큘럼 조정안을 위 기준으로 제안해 줘"라고 맡기면 됩니다.
