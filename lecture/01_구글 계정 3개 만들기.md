## 왜 3개인가요? — 용도별로 나누기

계정을 나누면 자료가 섞이지 않고, 실습하다 실수해도 주 계정이 안전합니다.

| 계정 | 이름 예시 | 용도 |
|---|---|---|
| ① **메인** | `hong.kim@gmail.com` | 개인용. 이미 있다면 새로 만들지 않고 이것을 사용 |
| ② **업무·강의** | `hong.work@gmail.com` | ChatGPT·Claude·NotebookLM·GitHub 가입, 업무 자료 보관 |
| ③ **실습·테스트** | `hong.lab@gmail.com` | 새 서비스를 시험해 보거나 공유 테스트할 때 사용 |

> ⚠️ 강사 안내: 계정을 여러 개 만드는 목적은 **용도 분리**입니다. AI 서비스의 무료 사용량 제한을 피하려고 계정을 돌려 쓰는 것은 각 서비스 약관 위반이 될 수 있다고 함께 안내합니다.

---

## 1-1. 첫 번째 계정 만들기 (약 7분)

**① 가입 화면 열기**
- Chrome 주소창에 `accounts.google.com/signup` 입력
- 또는 `google.com` → 오른쪽 위 **[로그인]** → **[계정 만들기]** → **[개인용]**

**② 이름** → 성, 이름 입력 → [다음]

**③ 생년월일·성별** → 입력 → [다음]

**④ Gmail 주소 정하기** (가장 오래 고민하는 단계)
- 추천 주소 대신 **[나만의 Gmail 주소 만들기]** 선택
- 영문 소문자, 숫자, 마침표(.)만 사용 가능. 한글, 띄어쓰기, `_`, `-` 는 불가
- **주소는 나중에 바꿀 수 없습니다.** 정하면 바로 종이에 적기

> 🧑‍🏫 강사 멘트: "**같은 뿌리 + 용도 꼬리표**로 지으면 세 계정을 주소만 보고 구분할 수 있습니다."

| 계정 | 예시 |
|---|---|
| ①메인 | `hong.gildong` |
| ②업무 | `hong.gildong.work` |
| ③실습 | `hong.gildong.lab` |

- "이미 사용 중"이면 실패가 아니라 누가 먼저 쓰는 것. 끝에 기수 번호·생일 숫자 등을 붙여 재시도 (예: `hong.gildong119`)
- ⚠️ Gmail은 **마침표를 구분하지 않습니다.** `hong.gildong` 과 `honggildong` 은 같은 주소라, 마침표 위치만 바꿔서는 새 주소가 되지 않습니다

**⑤ 비밀번호** → 영문·숫자·기호 섞어 8자 이상 → 확인칸에 한 번 더
- 나만 아는 문장에서 만들면 외우기 쉽습니다 (예: "소방학교 119기 화이팅!" → `Sobang119!fighting`)
- **비밀번호 표시**를 켜서 두 칸이 같은지 확인. **한/영 키**가 한글로 되어 있어 틀리는 경우가 가장 많습니다

**⑥ 전화번호 인증** → 문자로 온 6자리 코드 입력
- 화면에 따라 [건너뛰기]가 보이기도 하지만, **분실 시 복구를 위해 등록 권장**

**⑦ 복구 이메일** → 앞서 만든 다른 계정을 넣으면 좋음 (첫 계정이면 [건너뛰기])

**⑧ 검토 → 약관 [동의]**

**⑨ 확인** ✅ `google.com` 오른쪽 위에 이름 첫 글자 동그라미가 보이면 성공

## 1-2. 두 번째, 세 번째 계정 만들기

같은 순서를 반복하되, **로그아웃하지 말고** 아래 방법으로 만듭니다.

- 오른쪽 위 프로필 동그라미 → **[다른 계정 추가]** → **[계정 만들기]** → **[개인용]**
- ⚠️ **[로그아웃]을 누르지 않습니다.** 로그아웃하면 메인 계정이 닫혀 계정을 오가기 불편해집니다
- **복구 이메일 칸에 ①번 계정**을 넣어 두면, 비밀번호를 잊어도 서로 되찾을 수 있습니다.
- ③실습 계정은 체크리스트만 보여 주고 **혼자 해 보기**로 진행하면 자신감이 붙습니다

```
 ①메인  hong.gildong@gmail.com        ◀── 복구 이메일의 중심
 ②업무  hong.gildong.work@gmail.com   ──┘
 ③실습  hong.gildong.lab@gmail.com    ──┘
```

> 메인 계정 하나만 지키면 나머지 두 계정은 언제든 되찾을 수 있습니다. **메인 비밀번호는 특히 잘 보관**하게 하세요.

## 1-3. Chrome 프로필로 계정별 창 나누기 (강력 추천)

계정 3개를 한 창에서 바꿔 쓰면 "어느 계정으로 로그인했지?"가 계속 헷갈립니다. **Chrome 프로필**을 만들면 계정마다 별도 창이 생깁니다.

1. Chrome 오른쪽 위 **프로필 아이콘** (주소창 오른쪽) 클릭
2. **[추가]** → **[로그인]** → 해당 Google 계정으로 로그인
3. 프로필 이름(예: `업무`)과 **색상 테마**를 다르게 지정
4. 계정 3개 모두 반복 → 작업 표시줄에 창 색깔로 구분됩니다

| 프로필 | 색상 예시 | 이 창에서 가입할 서비스 |
|---|---|---|
| 메인 | 회색 | 개인 용도 |
| **업무** | 파랑 | ChatGPT, Claude, NotebookLM, (심화) GitHub·Vercel |
| 실습 | 초록 | 새 서비스 시험, 공유 테스트 |

> 💡 이후 모든 모듈은 **"업무" 프로필 창**에서 진행합니다.

## 자주 막히는 곳

| 상황 | 해결 |
|---|---|
| "이 전화번호는 너무 많이 사용되었습니다" | 한 번호로 만들 수 있는 계정 수에 제한이 있습니다. 시간을 두고 다시 하거나, ③번 계정은 다음 날 만듭니다 |
| 같은 강의장에서 인증이 계속 실패 | 같은 와이파이에서 짧은 시간에 가입이 몰리면 생길 수 있습니다. 휴대폰 데이터(핫스팟)로 바꿔 시도 |
| 인증 문자가 안 옴 | 1분 기다린 뒤 재전송. 국가 번호가 `+82`인지 확인 |
| 이미 Google 계정이 있음 | 그 계정을 ①메인으로 쓰고 ②③만 새로 만듭니다 |
| ③실습 계정에서 전화번호 인증이 막힘 | 무리하지 말고 숙제로. 수업 진행에는 ②업무 계정만 있으면 충분 |
| 강의장(공용) PC에서 Chrome 프로필을 만듦 | 동기화는 **[취소]**, 수업 후 프로필 삭제 (프로필 아이콘 → 톱니바퀴 → 해당 프로필 ⋮ → 삭제) |
