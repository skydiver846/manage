> 🎯 **이 모듈에서 만들 것:** **휴대폰으로 열리는** 내 강의평가 화면 주소
>
> 🤔 **생각해 보기:** 내 컴퓨터의 HTML 파일을 동료가 휴대폰으로 열려면 무엇이 필요할까요? (답은 이 모듈에서 찾아보세요. 점수 없음)

모듈 7·9의 강의평가 화면을 **누구나 휴대폰으로 여는 웹 주소**로 공개합니다. 폴더를 **끌어다 놓기만 하면** 주소가 생깁니다. 설치 없이 웹 브라우저만으로, 비용 0원입니다. 모든 작업은 **파란 "업무" Chrome 프로필 창**에서 합니다.

> ⏱ **수업에서는 약 30분입니다** (2일차 7교시 뒷부분, 09 맛보기 바로 다음). 0~6단계를 합니다. 7단계(GitHub 연결)는 8교시를 시작하며 함께 합니다.

## 흐름과 낱말 하나

```
 [강의평가] 폴더 ──(끌어다 놓기)──▶ Netlify ──▶ https://내이름.netlify.app
  └ index.html                       (공개)         (누구나 접속)
```

| 낱말 | 한 줄 설명 | 비유 |
|---|---|---|
| **배포 (Deploy)** | 내 컴퓨터의 화면 파일을 **웹 주소로 공개** | 가게 오픈 |

**Netlify** 는 화면 파일을 받아 웹 주소로 보여 주는 **게시 서비스**입니다. 몸풀기(03)에서 "HTML 파일 하나 = 프로그램"이었다면, 오늘은 "HTML 파일 하나 = **웹사이트**"가 됩니다.

## 0. 준비: `강의평가` 폴더에 `index.html` 넣기 (3분)

웹사이트의 **대문 파일** 이름은 반드시 **`index.html`** 이어야 합니다. Netlify에는 **폴더째** 올리므로 폴더도 하나 만듭니다.

1. `문서 > AI업무자료 > 03_AI결과물` 안에 새 폴더 `강의평가` 만들기
2. 화면 파일을 그 폴더에 `index.html` 이라는 이름으로 넣기

**방법 1: 실습 파일에서 내려받기** — 이 모듈 실습 파일의 **강의평가 집계 완성본 (index.html)** (모듈 9에서 고친 파일이 있으면 그것을 씁니다)

**방법 2: Claude 결과를 메모장에 저장하기**
1. Claude 답변 코드 블록 오른쪽 위 **복사** → **메모장**에 **Ctrl + V**
2. **파일 → 다른 이름으로 저장**
   - 파일 이름: `index.html`
   - 파일 형식: **모든 파일 (\*.\*)** ← 중요
   - 인코딩: **UTF-8**

✅ 폴더 안의 `index.html` 을 **더블클릭**해 Chrome에서 강의평가 화면이 열리면 준비 완료

> ⚠️ 가장 흔한 실수: 파일 형식을 "텍스트 문서"로 두면 `index.html.txt` 가 됩니다. 파일 탐색기 **[보기] → [파일 확장명]** 을 켜 두세요. 인코딩이 UTF-8이 아니면 한글이 깨집니다.

## 1. Netlify 가입 (3분)

1. `app.netlify.com` → **[Sign up]**
2. **[Sign up with Google]** → **업무 계정** 선택
3. 간단한 질문(용도 등)이 나오면 **개인(Personal)**, 무료 요금제(**Free**) 고르기

> ⚠️ 유료 요금제를 고르면 결제 정보 입력이 나옵니다. **Free** 를 고르세요. 무료 요금제는 매달 쓸 수 있는 양(크레딧)이 정해져 있어, 수업처럼 몇 번 배포하는 정도는 충분하지만 기관의 정식 서비스로 운영할 때는 요금제를 따로 검토해야 합니다.
> 가입하지 않고 `app.netlify.com/drop` 에 바로 끌어다 놓아도 주소가 생기지만, **1시간 뒤 사라집니다.** 수업에서는 꼭 가입한 상태로 합니다.

## 2. 끌어다 놓기 = 배포 (2분)

1. Netlify 첫 화면(**Sites** 또는 **Projects**)에서 **[Add new site]** → **[Deploy manually]** (메뉴 이름은 조금 다를 수 있습니다. "끌어다 놓기(Drag and drop)" 상자가 나오면 맞습니다)
2. 파일 탐색기에서 **`강의평가` 폴더**를 잡아 그 상자 위에 **끌어다 놓기**
3. 몇 초 뒤 `https://`로 시작하는 주소가 생깁니다 → 눌러서 강의평가 화면이 열리면 🎉 **배포 완료**

> 💡 **폴더째** 끌어다 놓습니다. `index.html` 파일 하나만 놓으면 안 될 수 있습니다.

## 3. 주소 이름 바꾸기 (2분)

처음 주소는 `gleaming-unicorn-1a2b3c.netlify.app` 처럼 무작위입니다. 알아보기 쉽게 바꿉니다.

1. 사이트 화면 → **Site configuration**(또는 Project configuration) → **Change site name**
2. 영문 소문자·숫자·하이픈(-)만 씁니다. 예: `fire-eval-hong`
3. 주소가 `https://fire-eval-hong.netlify.app` 로 바뀝니다

> ⚠️ 이미 다른 사람이 쓰는 이름이면 저장이 안 됩니다. 뒤에 숫자를 붙이세요.

## 4. 📱 휴대폰으로 열기: QR 만들기 (5분)

> 데스크톱 강의에서 QR은 **자료 배포용이 아니라 배포한 강의평가 화면을 교육생 휴대폰으로 열어 평가해 보는 용도**입니다. 링크를 PC끼리 나눌 때는 PC 메신저나 메일을 씁니다.

배포된 주소를 Chrome에서 연 상태에서:

| 방법 | 하는 법 |
|---|---|
| ① 오른쪽 클릭 | 페이지 빈 곳 오른쪽 클릭 → **이 페이지의 QR 코드 생성** |
| ② 메뉴 | 오른쪽 위 **⋮** → **전송, 저장, 공유** → **QR 코드 만들기** |

- 휴대폰 카메라로 찍으면 열립니다. **[다운로드]** 로 이미지 저장도 가능 (메뉴 이름은 Chrome 버전에 따라 다를 수 있음)
- 교육생끼리 **QR을 교환**해 서로의 화면에 평가를 내 보게 하면 반응이 좋습니다

## 5. 고쳐서 다시 끌어다 놓기 (4분)

**고치는 곳은 내 컴퓨터의 파일**입니다. Netlify에는 편집 기능이 없습니다.

1. `강의평가` 폴더의 `index.html` 을 **메모장**으로 열기 (오른쪽 클릭 → 연결 프로그램 → 메모장)
2. **Ctrl + F** 로 `강의평가 결과 집계` 를 찾아 `제12기 강의평가 결과` 로 변경 (`<title>` 과 `<h1>` 두 군데. 한 군데만 바꿔도 됩니다) → **Ctrl + S**
3. Netlify 사이트 화면 → **Deploys** 메뉴 → 아래쪽 끌어다 놓기 상자에 **`강의평가` 폴더를 다시** 끌어다 놓기
4. 휴대폰에서 **새로고침** → **같은 주소**에 바뀐 제목

```
● Published   Manual deploy   방금 전     ← 지금 보이는 화면
○             Manual deploy   10분 전     ← 이전 화면 (기록이 남음)
```

> 🎯 핵심: **주소는 그대로, 내용만 바뀝니다.** 이전 배포 기록이 남아 있어서, 화면이 깨지면 **Deploys** 에서 이전 배포를 누르고 **[Publish deploy]** 로 바로 되돌릴 수 있습니다.

> 🧑‍🏫 고칠 때 `<`, `>`, `"` 같은 **기호는 건드리지 말고 한글 글자만** 바꾸게 하세요. 화면이 깨진 교육생이 나오면 이전 배포로 되돌리는 시연 기회로 씁니다. 행정망 강의장 PC에서 Netlify 접속과 배포 주소 열림은 확인했습니다(2026. 10. 16.).

## 6. 마무리: 장부는 공유되지 않는다 (3분)

교육생끼리 서로의 QR로 평가를 낸 뒤 묻습니다. "짝꿍 휴대폰 결과표에 내가 낸 평가가 들어 있나요?" → **안 들어 있습니다.** 응답 수가 늘지 않습니다. 기록이 각자의 브라우저에만 저장되기 때문입니다. 20명이 내면 결과가 20군데로 흩어집니다.

```
 지금:     [내 휴대폰 장부]   [짝꿍 휴대폰 장부]   ← 따로따로
 공용 장부:  [내 휴대폰] ─┐
            [짝꿍 휴대폰] ┼──▶ 데이터베이스 (공용 장부)  ← 모두가 같은 결과표
            [담당자 PC] ─┘
```

모든 응답을 한곳에 모으려면 **공용 장부(데이터베이스)** 가 필요합니다. 이 과정에서는 개념만 짚습니다. 실무에서 여러 사람의 응답을 모을 때는 지금처럼 **네이버 폼**(또는 구글 설문·시트)으로 받고, 내려받은 결과를 AI에게 맡겨 정리하면 됩니다(모듈 3·6에서 한 방법).

> 🧑‍🏫 공용 장부 설명은 3분이면 충분합니다. "네이버 폼이 응답을 한곳에 모아 주는 것도 이런 장부가 뒤에 있기 때문"이라고 연결하면 쉽게 이해합니다.

## 7. 다음 실습 준비: Claude Code에 GitHub 연결하기 (8교시 시작, 5분)

2일차 오후(모듈 12)에 **내 PRD 화면**을 만들 저장소와 Claude Code 연결을 지금 미리 해 둡니다. 처음 연결할 때는 권한 승인 화면이 여러 번 나와 시간이 걸리기 때문입니다.

GitHub은 **파일과 고친 기록을 보관하는 창고**입니다(가입은 사전 과제). 모듈 12에서는 Claude Code가 이 창고에 코드를 쓰고, Netlify가 창고를 지켜보다가 바뀌면 **저절로 다시 배포**합니다. 오늘 손으로 끌어다 놓은 일을 AI와 Netlify가 대신하는 셈입니다.

**① 내 화면용 저장소 만들기**
1. `github.com` 로그인 → 오른쪽 위 **[+]** → **[New repository]**
2. **Repository name**: `my-tool`
3. **Private** 선택 — 내 업무 내용이 담기므로 이번에는 **비공개**
4. **Add a README file** ✅ 체크 (빈 저장소면 Claude Code가 작업을 시작하지 못합니다)
5. **[Create repository]**

**② Claude Code 연결**
1. 업무 Chrome 프로필에서 `claude.ai/code` 접속 (Claude Code **웹 버전**. 프로그램 설치가 필요 없어 행정망 PC에 적합)
2. **GitHub 연결**: 안내에 따라 Claude GitHub 앱을 설치
   - 저장소 선택에서 **Only select repositories** → `my-tool` **하나만** 선택
3. 작업할 저장소 목록에 `my-tool` 이 보이면 완료. **아직 아무것도 시키지 않습니다.**

> 🧑‍🏫 "모든 저장소(All repositories)"를 고르지 않게 합니다. **AI에게는 필요한 저장소만 열어 준다**는 보안 습관을 여기서 먼저 짚습니다. 7교시가 빠듯하면 8교시를 시작하며 함께 합니다. 이 단계를 해 두면 모듈 12의 0단계가 1~2분으로 줄어듭니다.

| | 오늘 (끌어다 놓기) | 모듈 12 (자동 배포) |

## 자주 막히는 곳

| 상황 | 해결 |
|---|---|
| `index.html.txt` 로 저장됨 | 메모장 저장 시 파일 형식 **모든 파일**, 탐색기에서 확장자 표시 켜기 |
| 한글이 깨짐 | 메모장 저장 시 인코딩 **UTF-8** |
| 주소를 열면 "Page not found" | 폴더 안 파일 이름이 정확히 `index.html` 인지, 폴더 안에 폴더가 또 있지 않은지 확인 |
| 끌어다 놓기 상자가 안 보임 | 사이트 화면 **Deploys** 메뉴 아래쪽, 또는 **[Add new site] → [Deploy manually]** |
| 주소 이름이 저장 안 됨 | 이미 쓰는 이름. 뒤에 숫자 붙이기, 영문 소문자·숫자·하이픈만 |
| 고쳤는데 휴대폰이 그대로 | 폴더를 **다시 끌어다 놓았는지**, 휴대폰 **새로고침** |
| 화면이 깨짐 | **Deploys** 에서 이전 배포 → **[Publish deploy]** 로 되돌리기 |
| `claude.ai/code` 에서 `my-tool` 이 안 보임 | GitHub 앱 설치 때 **Only select repositories** 에서 `my-tool` 을 골랐는지 확인 |
