# 모듈 4. 옵시디언: 내 업무 폴더를 보는 창

← [[03_프롬프트·파일·폴더 활용]] | 다음 → [[05_PRD 작성하기]]

방금 3-3에서 만든 `AI업무자료` 폴더를 **옵시디언**으로 엽니다. 이틀 동안 만드는 PRD와 메모를 여기서 보고 고칩니다.

- **옵시디언** = 내 컴퓨터 폴더 안의 **MD 파일**(`.md`)을 보기 좋게 보여 주고 고치게 해 주는 **무료 메모 앱**
- 파일은 **내 컴퓨터 폴더에 그대로** 있습니다. 옵시디언을 지워도 파일은 남습니다.
- MD 파일은 AI가 가장 잘 읽는 형식이라, 여기서 고친 파일을 그대로 Claude·Gemini에 건넵니다.

> 🧑‍🏫 **시간 배분 (2교시 끝 8분)**: 4-1 설치 3분 → 4-2 폴더 열고 파일 보기 5분. 설치가 막힌 분은 짝과 한 화면으로 보고, 메모장으로 같은 파일을 열어도 됩니다. 리허설 때 강의장 PC 한 대로 설치가 되는지 미리 확인하고, 관리자 권한 창 때문에 막히면 전산 담당에게 수업 전 일괄 설치를 부탁합니다.

## 4-1. 설치 (3분)

1. Chrome에서 `obsidian.md` 접속 → **[Download]** → Windows용 설치 파일 다운로드
2. 받은 파일 실행. "Windows의 PC 보호" 파란 창이 뜨면 **[추가 정보] → [실행]**
3. 설치가 끝나면 옵시디언이 자동으로 열립니다

> 💡 가입 없이 바로 씁니다. 동기화(Sync)·게시(Publish)는 유료 부가 기능이라 필요 없습니다.

## 4-2. 내 업무 폴더를 열고 파일 보기 (5분)

1. 첫 화면에서 **[Open folder as vault]** (폴더를 보관소로 열기)
2. `문서(Documents)` → **`AI업무자료`** 선택 → **[폴더 선택]**. 새로 만들지 않고 3-3에서 만든 폴더를 엽니다
3. 왼쪽에 `01_기획(PRD)` ~ `99_프롬프트` 폴더가 보이면 성공
4. `02_참고자료` → **`경주 여행 후기_예시`** 를 누릅니다. 3-2에서 AI에게 건넨 그 파일입니다
5. **Ctrl + E** 를 눌러 **읽기 보기 ↔ 편집 보기**를 바꿔 봅니다. 편집 보기에서는 `#`, `-` 같은 기호가 보이고, 읽기 보기에서는 제목·목록으로 보입니다

✅ 파일 탐색기에서 `문서 > AI업무자료` 를 열어 보면 **똑같은 폴더와 파일**이 있습니다. **옵시디언 = 내 폴더를 보는 창**입니다.

> 💡 이 창은 이틀 동안 계속 씁니다. **05** 내 PRD를 `01_기획(PRD)` 에 저장하고 여기서 열어 고치고, **07** 화면 시안을 보고 바꿀 점을 PRD에 바로 적고, **12** 그 PRD를 Claude Code에 건넵니다.

## 더 해 보기 (과정 뒤): 옵시디언 조금 더 쓰기

### 한국어로 바꾸기
왼쪽 아래 **톱니바퀴(Settings)** → **General(일반)** → **Language** → **한국어** → 앱 다시 시작

### AI가 만든 체크리스트를 체크하기
1. Claude에 입력: `내일 할 일 5개를 Markdown 체크리스트로 만들어 줘. 업무용 예시로.`
2. 옵시디언 `03_AI결과물` 폴더에서 **새 노트**(Ctrl + N)에 붙여넣기
3. **읽기 보기**(Ctrl + E)로 바꾸면 네모 칸이 생깁니다 → 눌러서 체크 ✅

### AI 답을 MD로 저장하기
1. ChatGPT·Claude 답변 아래 **[복사]** 아이콘 클릭 (Markdown 서식째 복사됩니다. 마우스로 드래그해 복사하면 표가 깨질 수 있습니다)
2. 옵시디언 `03_AI결과물` 폴더에 새 노트 → **붙여넣기(Ctrl + V)**
3. 제목에 날짜를 붙이면 찾기 쉽습니다. 예: `2026-11-07 경주 여행 일정`

### Markdown 기호는 3가지만

| 쓰는 법 | 결과 | 용도 |
|---|---|---|
| `# 제목` | 큰 제목 | 문서 제목 (`##` 은 소제목) |
| `- 항목` | • 항목 | 목록 |
| `**굵게**` | **굵게** | 강조 |

나머지(표, 체크리스트)는 외우지 않아도 됩니다. AI에게 "**Markdown으로 정리해 줘**"라고 하면 알아서 씁니다. `[[파일이름]]` 을 쓰면 다른 노트로 가는 **링크**가 됩니다.

## 자주 막히는 곳

| 상황 | 해결 |
|---|---|
| 설치 파일 실행 시 경고 | [추가 정보] → [실행]. 공식 사이트(`obsidian.md`)에서 받은 파일인지 확인 |
| 관리자 권한 창이 뜨거나 설치가 막힘 | 짝과 한 화면으로 보고, 내 파일은 **메모장**으로 열어도 됩니다. 기관 PC 설치는 전산 담당에게 확인 |
| `AI업무자료` 폴더가 없음 | 3-3 ③으로 돌아가 만들거나, **[Create new vault]** → 이름 `AI업무자료`, 위치 `문서` |
| 후기 파일이 안 보임 | 다운로드 폴더에 있는 `경주 여행 후기_예시.md` 를 `02_참고자료` 로 옮기기 |
| 보관소를 어디 열었는지 모름 | 왼쪽 아래 보관소 이름 클릭 → [보관소 관리] → 경로 확인 |
