# 모듈 4. 옵시디언 설치와 MD 파일 만들기

← [[03_프롬프트·파일·폴더 활용]] | 다음 → [[05_PRD 작성하기]]

## 옵시디언(Obsidian)이란?

- 내 컴퓨터 폴더 안의 **Markdown(.md) 파일**을 편하게 쓰고 연결하는 **무료 메모 앱**
- 파일이 **내 컴퓨터에 그대로 저장**됩니다. 앱을 지워도 파일은 남습니다.
- 그대로 ChatGPT·Claude·NotebookLM에 올릴 수 있어 **AI용 자료 창고**로 좋습니다.

### Markdown(MD)이란?

기호 몇 개로 제목·목록·표를 표시하는 **아주 단순한 글쓰기 규칙**입니다. 메모장으로도 열리고, AI가 구조를 정확히 이해합니다.

---

## 4-1. 설치 (Windows, 약 5분)

1. Chrome에서 `obsidian.md` 접속
2. **[Download]** → Windows용 설치 파일(.exe) 다운로드
3. 다운로드한 파일 실행 → 설치가 자동으로 진행됩니다
   - "Windows의 PC 보호" 파란 창이 뜨면 **[추가 정보] → [실행]**
4. 설치가 끝나면 옵시디언이 자동으로 열립니다

> 💡 옵시디언은 가입 없이 바로 쓸 수 있습니다. 동기화(Sync)·게시(Publish)는 유료 부가 기능이며 이번 수업에는 필요 없습니다.

## 4-2. 보관소(Vault) 만들기

**보관소 = 옵시디언이 관리하는 폴더 하나**입니다.

1. 첫 화면에서 **[Create new vault]** (새 보관소 만들기) → **[Create]**
2. **Vault name**: `AI업무자료`
3. **Location**: [Browse] → `문서(Documents)` 폴더 선택
4. **[Create]** 클릭

### 한국어로 바꾸기
- 왼쪽 아래 **톱니바퀴(Settings)** → **General(일반)** → **Language** → **한국어** → 앱 다시 시작

### 폴더 구조 만들기 (모듈 3에서 설계한 구조)
- 왼쪽 파일 탐색기 위 **[새 폴더]** 아이콘으로 아래 4개 생성

```
📁 AI업무자료
 ├─ 📁 01_기획(PRD)
 ├─ 📁 02_참고자료
 ├─ 📁 03_AI결과물
 └─ 📁 99_프롬프트
```

> ✅ Windows 파일 탐색기에서 `문서 > AI업무자료` 를 열어 보면 **똑같은 폴더가 실제로 있습니다.** "옵시디언 = 내 폴더를 보는 창"임을 꼭 확인시켜 주세요.

---

## 4-3. 첫 MD 파일 만들기

1. `99_프롬프트` 폴더에서 마우스 오른쪽 → **[새 노트]**
2. 제목: `자주 쓰는 프롬프트`
3. 아래 내용을 그대로 따라 입력합니다

```markdown
# 자주 쓰는 프롬프트

## 문서 요약
- 핵심 3줄 요약
- 해야 할 일 목록
- **문서에 없는 내용은 지어내지 말 것**

## 안내문 작성
| 요소 | 내용 |
|---|---|
| 역할 | 교육운영 담당자 |
| 형식 | 제목 + 5개 항목 |

- [ ] 결과는 원문과 대조하기
```

4. **Ctrl + E** 를 눌러 **편집 ↔ 읽기 보기**를 전환해 봅니다

## 4-4. Markdown 핵심 문법 7가지

| 쓰는 법 | 결과 | 용도 |
|---|---|---|
| `# 제목` | 큰 제목 | 문서 제목 |
| `## 소제목` | 중간 제목 | 섹션 구분 |
| `- 항목` | • 항목 | 목록 |
| `1. 항목` | 1. 항목 | 순서 있는 목록 |
| `**굵게**` | **굵게** | 강조 |
| `- [ ] 할 일` | ☐ 할 일 | 체크리스트 |
| `\| 칸 \| 칸 \|` | 표 | 비교·정리 |

**옵시디언 전용 기능 하나:** `[[파일이름]]` 을 쓰면 다른 노트로 가는 **링크**가 됩니다. 이 강의자료도 그렇게 연결되어 있습니다.

## 4-5. AI 결과물을 MD로 저장하기

ChatGPT·Claude의 답을 옵시디언에 보관하는 방법:
1. 답변 아래 **[복사]** 아이콘 클릭 (서식이 Markdown으로 복사됩니다)
2. 옵시디언 `03_AI결과물` 폴더에 새 노트 → **붙여넣기(Ctrl + V)**
3. 제목에 날짜를 붙이면 찾기 쉽습니다. 예: `2026-10-01 오리엔테이션 안내문`

> 답변을 마우스로 드래그해 복사하면 표가 깨질 수 있습니다. 반드시 **복사 아이콘**을 쓰게 하세요.

## 4-6. 실습 파일을 보관소로 옮기기

모듈 3에서 **다운로드** 폴더에 받은 `PRD_교육생 출석부.md` 를 보관소로 옮깁니다.

1. 파일 탐색기 **다운로드** 폴더에서 파일을 잡고 → 옵시디언 왼쪽 **`01_기획(PRD)`** 폴더 위에 끌어다 놓기
   - 어려우면 탐색기에서 **잘라내기(Ctrl + X)** → `문서 > AI업무자료 > 01_기획(PRD)` 에 **붙여넣기(Ctrl + V)**
2. 옵시디언에서 열어 보면 모듈 3에서 AI에게 건넨 파일이 표와 체크박스로 보입니다
3. `자주 쓰는 프롬프트` 노트 맨 아래에 `[[PRD_교육생 출석부]]` 를 입력해 링크 만들기 체험

### 모듈 4를 마친 보관소 모습

```
📁 AI업무자료
 ├─ 📁 01_기획(PRD)
 │   └─ 📄 PRD_교육생 출석부
 ├─ 📁 02_참고자료
 ├─ 📁 03_AI결과물
 │   └─ 📄 2026-10-02 오리엔테이션 안내문
 └─ 📁 99_프롬프트
     └─ 📄 자주 쓰는 프롬프트
```

> 🧑‍🏫 강사 포인트: 4-2에서 보관소를 만든 직후 **Windows 파일 탐색기**를 옆에 띄워 `문서 > AI업무자료` 가 진짜 폴더로 있는 것을 보여 주세요. "옵시디언 = 내 폴더를 보는 창"이 각인되지 않으면 모듈 6에서 NotebookLM에 파일을 올릴 때 **파일을 못 찾습니다.**

## 자주 막히는 곳

| 상황 | 해결 |
|---|---|
| 설치 파일 실행 시 경고 | [추가 정보] → [실행]. 공식 사이트(`obsidian.md`)에서 받은 파일인지 확인 |
| 보관소를 어디 만들었는지 모름 | 왼쪽 아래 보관소 이름 클릭 → [보관소 관리] → 경로 확인 |
| 표가 표로 안 보임 | 표 위아래에 빈 줄이 있는지, 둘째 줄 `\|---\|---\|` 가 있는지 확인 |
| `#` 을 쳤는데 제목이 안 됨 | `#` 뒤에 **띄어쓰기**가 있어야 합니다 |
| `\|` 기호를 못 찾음 | **Shift + 원화(₩) 또는 역슬래시(\\)** 키 |
| 문법 실습을 복사·붙여넣기로 함 | **직접 타이핑**해야 기호가 모양으로 바뀌는 순간을 볼 수 있습니다 |
| 기관 PC라 설치가 막힘 | 전산 담당자에게 설치 승인 요청. 그동안은 메모장에서 `.md` 확장자로 저장해도 실습 가능 |
