# 무료 계정판 강의자료 (보존본)

Claude **Team(유료)** 기준으로 바꾸기 전, **무료 계정 / Pro 두 트랙** 기준으로 쓴 강의자료입니다. 기관 결제가 안 되어 무료 계정으로 진행해야 할 때 이 자료를 씁니다.

| 위치 | 내용 |
|---|---|
| `lecture/` | 무료/Pro 트랙 기준 강의자료 원본 (보존 시점: 2026-10-03) |
| 교육생 사이트 | https://fire-ai-classroom.vercel.app/fire-ai-free/ (목록에는 링크하지 않음) |

다시 쓰려면 `lecture/` 를 저장소 맨 위 `lecture/` 에 덮어쓰고 `tools/classroom` 에서 `npm run build` 합니다.
