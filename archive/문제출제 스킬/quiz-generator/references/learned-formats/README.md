# 학습된 문제지 양식 저장소

사용자가 기존에 쓰던 문제지 양식 파일(hwpx/docx/pdf 등)을 처음 받으면, SKILL.md의 5단계에 따라 그 구조를 파악한 뒤 여기에 사용자별 하위 폴더를 만들어 저장한다. 예: `learned-formats/central-fire-academy-objective-card/`.

각 폴더에는 두 가지를 함께 둔다.

1. **`reference.hwpx`(또는 `.docx`/`.pdf`) — 사용자가 준 원본 파일 그 자체(필요하면 수정 반영본).** 처음에는 "구조를 서술형으로만 적어두면 충분하다"고 생각했지만, 실제로 hwpx 같은 서식은 표 셀 구성·글자모양 ID·테두리 정의가 파일마다 달라서 글로만 옮겨서는 다시 똑같이 못 만든다. 그래서 원본 파일을 실제로 보관해두고, 다음에 문제를 낼 때마다 이 파일을 복제해서 내용만 채우는 것이 정확하고 빠르다.
2. **`format-notes.md` — 사람이 읽을 서술형 설명.** 원본 서식이 무엇인지, 사용자가 요청해서 바꾼 부분이 있으면 무엇을 왜 바꿨는지, 재사용할 때 어떤 칸에 무엇을 채워야 하는지를 적어둔다. 파일을 열어보지 않고도 어떤 양식인지 빠르게 파악하는 용도다.

다음에 같은 사용자가 양식 지정 없이 요청하면 이 폴더를 먼저 확인하고, 폴더가 하나뿐이면 그것을 바로 재사용한다. 여러 개가 쌓이면 요청 시점에 어떤 양식을 쓸지 짧게 확인한다.

`format-notes.md`에 포함하면 좋은 항목:

- 원본 서식 이름과 출처(예: "중앙소방학교 평가관리규정 별지 제4호서식")
- 전체 구조(표/문단 구성, 문항 번호 표기 방식, 보기 배치, 정답란·소속란 등 입력 칸 위치)
- 사용자 요청으로 원본에서 바꾼 부분과 그 이유(날짜와 함께 기록해두면 변경 이력 추적에 좋다)
- 재사용 시 각 칸에 무엇을 채워야 하는지 — 새 문항마다 채울 칸과, 고정값으로 이미 채워둔 칸(예: 소속란)을 구분해서 적는다
- 절대 건드리면 안 되는 부분(표 구조, 글자모양, 공식 서식 번호 등)

지금은 `central-fire-academy-objective-card/` 하나가 들어 있다 — 중앙소방학교 객관식 문제카드(별지 제4호서식)를 실무에 맞게 다듬은 버전이며, `scripts/make_quiz_cards.py` 로 채운다.

> **조직(Team)에 배포된 스킬은 대화 중에 파일을 영구히 바꿀 수 없다.** 새 양식을 받으면 그 대화 안에서만 쓰고, 계속 쓸 양식이면 "스킬 관리자에게 이 양식을 스킬에 추가해 달라고 요청하세요"라고 안내한다.
