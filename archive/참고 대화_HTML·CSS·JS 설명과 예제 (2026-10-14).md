## 1. HTML, CSS, JS 설명

**질문:** html, css, js를 알기쉽게 설명해줘

**답변:**

HTML, CSS, JS는 웹페이지를 만드는 세 가지 기본 재료입니다. 집을 짓는 것에 비유하면 이해하기 쉽습니다.

### HTML: 뼈대 (구조)

집으로 치면 기둥, 벽, 방 구조에 해당합니다. "여기에 제목이 있고, 여기에 문단이 있고, 여기에 버튼이 있다"처럼 무엇이 있는지를 정합니다.

```html
<h1>소방학교 공지사항</h1>
<p>이번 주 교육 일정을 안내드립니다.</p>
<button>확인</button>
```

### CSS: 꾸미기 (디자인)

집으로 치면 페인트, 벽지, 가구 배치입니다. 같은 뼈대라도 CSS에 따라 완전히 다른 모습이 됩니다. 어떻게 보이는지를 정합니다.

```css
h1 {
  color: red;        /* 글자색 */
  font-size: 32px;   /* 글자 크기 */
}
button {
  background: navy;  /* 배경색 */
  color: white;
}
```

### JavaScript: 움직임 (동작)

집으로 치면 전등 스위치, 초인종, 자동문입니다. 사용자가 뭔가 했을 때 반응하게 만듭니다.

```javascript
document.querySelector("button").onclick = function () {
  alert("확인되었습니다!");
};
```

### 한눈에 비교

| | 역할 | 비유 | 질문 |
|---|---|---|---|
| HTML | 구조·내용 | 뼈대 | 무엇이 있나? |
| CSS | 모양·디자인 | 인테리어 | 어떻게 보이나? |
| JS | 동작·기능 | 전기·자동장치 | 어떻게 움직이나? |

### 세 가지를 합친 간단한 예시

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    /* CSS: 꾸미기 */
    button { background: navy; color: white; padding: 10px; }
  </style>
</head>
<body>
  <!-- HTML: 구조 -->
  <h1 id="title">안녕하세요</h1>
  <button onclick="change()">클릭</button>

  <script>
    // JS: 동작
    function change() {
      document.getElementById("title").innerText = "클릭하셨네요!";
    }
  </script>
</body>
</html>
```

이 코드를 `test.html`로 저장해서 브라우저로 열면, 버튼을 누를 때 제목 글자가 바뀝니다.

### 배우는 순서 추천

1. HTML을 먼저 익힙니다. 가장 쉽고 결과가 바로 눈에 보입니다.
2. CSS로 예쁘게 꾸밉니다.
3. JS로 기능을 추가합니다. 셋 중 가장 어렵지만 가장 재미있습니다.

## 2. 실행 예시

## 4. JavaScript 활용 예시 10가지

**질문:** html, css, js중에 js가 엄청난 기능을 한다며 10개만 예를 들어서 보여줄래

**답변:** 직접 눌러 볼 수 있는 10가지 예시를 보여드렸습니다.

| 번호 | 예시 | JS가 하는 일 |
|---|---|---|
| 1 | 계산하기 | 입력값을 읽어 계산하고 결과를 표시 |
| 2 | 입력값 검사 | 입력 형식이 맞는지 실시간으로 판단 |
| 3 | 실시간 시계 | 타이머로 1초마다 화면 갱신 |
| 4 | 다크 모드 | 버튼 하나로 스타일을 통째로 변경 |
| 5 | 할 일 목록 | 화면 요소를 새로 만들고 삭제 |
| 6 | 글자 수 세기 | 입력 길이를 세고 기준 초과 시 경고 |
| 7 | 무작위 색 | 난수로 값을 만들어 화면에 적용 |
| 8 | 접고 펴는 안내문 | 클릭에 따라 내용을 보이기와 숨기기 |
| 9 | 목록 검색 | 많은 데이터에서 조건에 맞는 것만 걸러냄 |
| 10 | 퀴즈 채점 | 답을 판단하고 점수를 누적 |

공통점은 화면을 새로고침하지 않고 그 자리에서 바로 바뀐다는 점입니다.

## 5. 3D 방 인테리어

**질문:** 3d로 방 인테리어 꾸미는 html 만들어줘

**답변:** three.js로 만든 3D 방 꾸미기 파일을 만들었습니다.

- 파일: `room3d.html` (인터넷 연결 필요, 3D 라이브러리를 인터넷에서 불러옴)
- 화면 돌리기: 빈 곳을 끌면 회전, 휠로 확대/축소
- 가구 옮기기: 가구를 끌어 이동 (벽 밖으로는 나가지 않음)
- 가구 11종: 침대, 소파, 책상, 의자, 책장, 원형 테이블, 화분, 스탠드 조명, 러그, TV 장식장, 옷장

- 방 설정: 벽 색, 바닥 종류(마루, 타일, 단색), 낮/밤 전환
- 저장: 브라우저에 저장/불러오기, 이미지(PNG) 저장

## 7. 일정 등록 사이트 (캘린더 + 간트차트)

**질문:** 일정을 등록하면 내 일정캘린더에 등록해서 보여주고, 프로텍트의 경우는 간트차트로 보여주는 세련되고 애니메이션틱한 그런 디자인의 일정등록 사이트를 html, css, js 로만 만들어줘

**답변:** 일정은 캘린더에, 프로젝트는 간트차트에 보여주는 사이트를 만들었습니다. ("프로텍트"는 "프로젝트"로 이해했습니다.)

- 파일: `planner.html` (HTML, CSS, JS만 사용, 파일 하나로 동작)
- 등록 창에서 "일정"과 "프로젝트"를 고릅니다.
  - 일정: 제목, 날짜, 시작/종료 시간, 색, 메모 → 월간 캘린더에 표시
  - 프로젝트: 제목, 시작일, 종료일, 진행률, 색, 메모 → 간트차트에 표시
- 캘린더: 날짜 클릭 시 오른쪽에 그날 일정 표시, 더블클릭 또는 "+" 버튼으로 바로 등록
- 간트차트: 막대를 끌어 기간 이동, 양 끝을 끌어 기간 조절, 보기 간격(크게/보통/촘촘히) 전환, 오늘 위치 표시
- 저장: 브라우저에 자동 저장, 삭제 후 "되돌리기" 가능
- 움직임: 막대가 자라나는 효과, 오늘 표시선, 숫자 올라가는 효과, 등록 창 전환 효과
