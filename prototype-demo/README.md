# 우리 가족 여행 준비물 체크 (강의용 프로토타입)

빌드 도구 없이 HTML 파일 하나로 동작하는 여행 준비물 체크 프로토타입입니다. 준비물을 **누구 것**(가족 전체 / 나 / 배우자 / 아이 / 할머니)과 함께 적고, 챙기면 체크합니다. 가족별 챙김률을 내고, 50% 미만은 "서둘러요", 100%는 "다 챙김", 그 밖은 "순조로움"으로 표시합니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 완성본 (PRD v0.3 + 저장·예시·마지막 추가 취소·두 번 눌러 초기화·목록 내려받기(CSV)) |
| `steps/1-html.html` ~ `3-js.html` | 모듈 09의 HTML → CSS → JavaScript 단계별 파일 |
| `examples/` | 모듈 09 응용 실습 완성 예시 (일정 플래너, 3D 방 꾸미기) |
| `network-check.html` | 강의장 PC 접속 점검 페이지 |

- 기준 PRD: `lecture/실습자료/PRD_경주 여행 준비물 (v0.3 완성본).md`
- 기록은 브라우저 저장소(localStorage, 키 `trip-checklist-v1`)에만 저장됩니다. 다른 휴대폰·PC와 공유되지 않습니다.

## 로컬에서 실행

```bash
cd prototype-demo
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

파일을 더블클릭해 열어도 그대로 동작합니다.
